# キーボードショートカット仕様

## 概要
ペイン操作を快適に行うためのキーボードショートカット一覧および仕様です。

---

## ショートカットキー一覧

| キー | 対象ペイン | 機能 | 説明 |
|---|---|---|---|
| **R** | 左・真ん中 | **再読み込み（更新）** | キャッシュを無効化し、現在のフォルダの最新ファイル一覧を即座に再取得します（ツールバーの更新ボタンと同一）。Windows等でファイル変更が遅延反映される場合にも即座に反映されます。 |
| **N** | 左・真ん中 | **リネーム** | 現在アクティブ・フォーカスされている行のファイル／フォルダのリネームダイアログを表示します（名前・拡張子を個別に編集可能）。 |
| **A** | 左・真ん中 | フォルダ作成 | 新規フォルダ作成ダイアログを表示します。 |
| **T** | 左・真ん中 | テキスト作成 | 新規テキストファイル作成ダイアログを表示します。 |
| **O** | 左・真ん中 | フォルダを開く | 現在のフォルダをOS（Finder / Explorer）で開きます。 |
| **H** | 全ペイン | 使い方ヘルプ | 使い方・ショートカット一覧モーダルを表示します。 |
| **L** | 左・真ん中 | フィルタ切り替え（次） | 拡張子フィルタを次の項目へ切り替えます。 |
| **Shift + L** | 左・真ん中 | フィルタ切り替え（前） | 拡張子フィルタを前の項目へ切り替えます。 |
| **D** | 左・真ん中 | 最新更新日集計 | 選択中フォルダの配下を再帰集計し、Date列に最新日時を表示します。 |
| **G** | 左・真ん中 | Git状態一括確認 | ペイン内の全フォルダのGit状態（変更・未Push・未Pull）を並列確認します。 |
| **Ctrl/Cmd + P** | 左・真ん中 | フォルダ内検索 | フォルダ内 indexed 検索モーダルを表示します。 |
| **Ctrl/Cmd + F** または **/** | 左・真ん中 | 検索ボックスフォーカス | ペイン内のファイル名検索ボックスに即座にフォーカスします。 |
| **Enter** | 検索ボックス | 検索ヒット（次へ） | 検索ヒットの次のアイテムへ移動し選択・スクロールします（末尾時は先頭へラップ）。 |
| **Shift + Enter** | 検索ボックス | 検索ヒット（前へ） | 検索ヒットの前のアイテムへ移動し選択・スクロールします（先頭時は末尾へラップ）。 |
| **Escape** | 検索ボックス | 検索クリア | 検索ボックスのクエリを全消去し、ファイル一覧にフォーカスを復帰します。 |
| **Ctrl/Cmd + F** | Markdownビューワ | 本文検索 | Markdownエディタ・ビューワ内で本文検索バーに即時フォーカスします。 |
| **Enter** | Markdown検索バー | 次のマッチへ移動 | 次の一致箇所へエディタ選択とプレビューハイライトを移動・スクロールします。 |
| **Shift + Enter** | Markdown検索バー | 前のマッチへ戻る | 前の一致箇所へエディタ選択とプレビューハイライトを移動・スクロールします。 |
| **Escape** | Markdown検索バー | 検索クリア | 検索クエリをクリアし、エディタにフォーカスを復帰します。 |
| **Alt + S** | 全体 | 左右ペイン同期移動 | 左右ペイン（左ペインと中央ペイン）の同期移動モードをON/OFF切り替えます。 |
| **← / →** | 画像ビューワー | 前後の画像へ移動 | 同一フォルダ内の前後の画像ファイルへプレビューを切り替えます。 |
| **+ / - / 0** | 画像ビューワー | ズーム操作 | 画像の拡大(+)、縮小(-)、等倍リセット(0)を行います。 |
| **Ctrl/Cmd + R** | 左・真ん中 | フォルダ履歴検索 | 過去に移動したフォルダ履歴をインクリメンタル検索します。 |
| **Ctrl/Cmd + H** | 左・真ん中 | ホームへ移動 | ホームディレクトリへ移動します。 |
| **Ctrl/Cmd + ← / ↓** | 左・真ん中 | 戻る | 履歴を一つ戻ります。 |
| **Ctrl/Cmd + →** | 左・真ん中 | 進む | 履歴を一つ進みます。 |
| **Ctrl/Cmd + ↑** | 左・真ん中 | 上の階層へ | 親ディレクトリへ移動します。 |
| **Ctrl/Cmd + A** | 左・真ん中 | 全選択 | 表示中のアイテムをすべて選択します。 |
| **Ctrl/Cmd + Shift + A** | 左・真ん中 | 選択解除 | 選択をすべて解除します。 |
