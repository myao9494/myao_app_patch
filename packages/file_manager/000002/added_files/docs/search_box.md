# 検索ボックス仕様書 (Search Box)

## 概要
ペイン内のファイルおよびフォルダ一覧をインクリメンタルに高速フィルタリングする検索ボックス機能です。キーボードショートカットからの即時呼び出し、正規表現対応、ワンクリッククリア、ヒット件数のリアルタイム表示を提供します。

---

## 主な機能

1. **クイックフォーカス (`Ctrl/Cmd + F` または `/`)**:
   - ペイン（左または中央）がアクティブな状態で `Ctrl+F`（Macでは `Cmd+F`）または `/` キーを押すと、即座に検索入力欄にフォーカスが当たり、テキストが全選択されます。
   - ツールバーの `<Search>` ボタンをクリックすることでも検索ボックスにフォーカスできます。

2. **Enter / Shift + Enter によるヒット間移動**:
   - **`Enter`**: 次の検索ヒットへフォーカス・選択を移動し、スムーズにスクロールします（最後のヒットに達した場合は先頭へラップアラウンド）。
   - **`Shift + Enter`**: 前の検索ヒットへフォーカス・選択を移動します（先頭のヒットの場合は末尾へラップアラウンド）。
   - 入力欄にフォーカスしたまま連続でキー押下でき、ブラウザ標準のページ内検索（Ctrl+F）と同様の直感的な送り操作が可能です。

3. **エスケープキーによる即時解除 (`Escape`)**:
   - 検索入力中に `Escape` キーを押すと、入力クエリが自動的にクリアされ、ファイル一覧にフォーカスが復帰します。

4. **ワンクリッククリアボタン (`×`)**:
   - クエリ入力中のみ表示される `×` ボタンをクリックすることで、素早く検索をリセットできます。

5. **リアルタイム件数・ヒット位置表示バッジ**:
   - 検索ボックス右側に、件数バッジがリアルタイム表示されます。
     - **検索中**: 現在のヒット位置と総ヒット件数（例: `1 / 5`）
     - **未検索時**: 現在のフォルダ内総項目数と全件数（例: `24 / 24`）

6. **柔軟な検索モード**:
   - 部分一致検索（大文字小文字無視、日本語対応）。
   - 正規表現トグルボタン（`.*`）による高度な正規表現検索（不正な正規表現が入力された場合は通常検索に自動フォールバック）。
