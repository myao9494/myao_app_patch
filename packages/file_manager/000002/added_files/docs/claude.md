# 開発仕様書

## 概要
ファイルマネージャの仕様をまとめる。

## 基本方針
- 言語: 日本語
- テスト駆動開発(TDD)推奨
- ドキュメントは `docs/` に集約

## 機能仕様
### フォルダ履歴
- 履歴はバックエンド `folder_history.json` に保存する。
- 最大300件まで保持する。
- アプリケーション起動時にバックエンドから履歴を読み込む。
- **起動時の競合対策**:
    - 起動直後のフォルダ移動（`addToHistory`）と、初期ロード（`fetchHistory`）が競合しないように制御する。
    - 読み込み完了まで（`isInitialized`がfalseの間）は、`addToHistory`等によるバックエンドへの保存をスキップする。
    - 読み込み完了時に、ローカルで追加された履歴とバックエンドの履歴をマージし、バックエンドに保存し直す。

### 環境設定 (Frontend)
- `frontend/src/config.ts` の `getNetworkDrivePath` は環境変数 `.env` を参照する。
- 以下の変数が定義されている場合、その値を使用する。
    - `VITE_NETWORK_DRIVE_PATH_WINDOWS`: Windows用のパス
    - `VITE_NETWORK_DRIVE_PATH_MAC`: macOS/Linux用のパス
- 定義されていない場合はデフォルト値を使用する。
- **注意**: フロントエンドの環境変数は `frontend/.env` に記述すること（`backend/.env` は参照されない）。

### UI改善
- **長いファイルパスの表示**:
    - パス入力欄を `<textarea>` に変更し、長いパスが折り返して表示されるようにした。
    - 履歴ドロップダウンの項目も折り返し表示に対応し、パス全体が確認できるようにした。
- **VS Codeで開くボタン**:
    - ファイル選択状態に関わらず、常に「現在のフォルダ」をVS Codeで開くように変更した。

### ファイル操作
- **Zip解凍**:
    - `.zip`ファイルに対する右クリックメニュー（コンテキストメニュー）に「Zip解凍」機能を実装。
    - 選択したファイルと同じディレクトリに、ファイル名（拡張子なし）のフォルダを作成し、その中に解凍する。
    - 展開先のフォルダが既に存在する場合は、フォルダ名の末尾に連番を付与し、既存ファイルと衝突しないよう安全に解凍する設計とした。

### PWA配信
- **アイコン設定**:
    - ブラウザのタブやPWAインストール時に表示されるアイコンをカスタマイズ。
    - `frontend/public/favicon.svg` をベースに、`icon-192.png` および `icon-512.png` を生成。
    - `index.html` で `favicon.svg` をファビコンとして指定。
    - ビルド済み（`dist/`）に最新のアイコンが反映されるよう、`npm run build` を実行済み。

### file_index_service の PWA配信対応
- **GUIのポート変更**:
    - `file_index_service` がPWA配信対応となったため、Viteの開発サーバー (localhost:5174) への依存を廃止。
    - file_manager内のGUIへのリンクやドキュメントを、FastAPIバックエンド/PWA配信を兼ねる `http://localhost:8080` に統合した。

### 外部連携用API (`/api/open-path`)
- **フォルダの表示**:
    - `GET /api/open-path?path=...` を叩くことで、指定したフォルダを本アプリのフロントエンドで開くことができる。
    - 以前は `localhost:5173` に固定されていたが、現在は相対パス (`/?path=...`) を使用するように改善され、ポート番号に関わらず動作する（例: `http://localhost:8001/api/open-path?path=...`）。
    - ファイルパスが指定された場合は、OSのデフォルトアプリでファイルを開き、ブラウザの非表示タブを自動で閉じる。

### 内蔵エディタ
- **テキスト/コードファイル (FileEditorModal)**:
    - **最上部1行集約ヘッダー & 作業領域最大化**:
        - タイトル、検索バー、言語バッジ、行数・保存状態表示、キャンセル・保存ボタンを最上部ヘッダーの横1行に完全集約。
        - ツールバーやフッター・ステータスバーを撤廃し、コード編集領域を画面いっぱいに最大化。
    - **VS Code Dark+ 準拠のシンタックスハイライト**:
        - Python（キーワード、関数名、クラス名、組み込み関数/型、self/cls、デコレータ、複数行docstring `"""..."""`、コメント等）をVS Codeと同一のカラーパレットで鮮明に着色。
        - TypeScript, JavaScript, JSON, Shell, CSS, HTML, YAML, TOML, SQL, dotenv 等もサポート。
    - **エディタ内検索**:
        - `Cmd/Ctrl+F` で検索バー即時フォーカス。`Enter` / `Shift+Enter`（および `▲` / `▼`）で循環移動。
        - 構文ハイライトを壊さずに検索ヒットを `<mark>` 重ね合わせ表示。
        - `Escape` で検索解除・エディタ復帰。
    - `Cmd/Ctrl+S` で保存、`Tab` / `Shift+Tab` でインデント操作。
- **Markdownファイル (MarkdownEditorModal)**:
    - **最上部1行集約ヘッダー & 作業領域最大化**:
        - タイトル、検索バー、モード切替（Edit / Split / Preview）、行数・保存状態、キャンセル・保存ボタンを最上部ヘッダーの横1行に完全集約。
        - 下部フッターや装飾ツールバーを完全排除し、画面のほぼ全高をテキスト編集・プレビュー領域に最大化。
    - **検索ボックス機能**:
        - `Cmd/Ctrl+F` で検索入力欄に即時フォーカス。
        - `Enter` / `Shift+Enter`（および `▼` / `▲` ボタン）で次のヒット・前のヒットへ循環移動。
        - リアルタイム位置・件数表示バッジ（`現在位置 / 総ヒット件数`）。
        - エディタ側（Textarea）の選択範囲・スクロール移動と、プレビュー側（HTML）の安全な `<mark>` ハイライト＆スクロールが完全連動。
        - `.*` ボタンによる正規表現検索切り替え、`Escape` による検索解除。
    - **キーボードショートカット**:
        - `Cmd/Ctrl+B` 太字, `Cmd/Ctrl+I` 斜体, `Cmd/Ctrl+Shift+[ ]` 見出しレベル操作, `Cmd/Ctrl+L` チェックリスト, `Cmd/Ctrl+:` 箇条書き, `Tab` インデント, `Cmd/Ctrl+S` 保存。
    - プレビューではタスクリストのチェック操作、コールアウト、WikiLink等をサポート。
- **エディタ選択設定**:
    - ハンバーガーメニューからテキストファイル/Markdownのオープン先を選択可能（Web App / VS Code / Obsidian）。
    - 設定は localStorage に保存される。

### Antigravity起動仕様 (macOS)
- **複数パッケージ自動検出とopenコマンドによる起動**:
    - `POST /api/open/antigravity` APIにおいて、macOS上に存在する以下のインストールパッケージ候補を自動検索し、実在するアプリケーションパッケージ（`.app`）を `open -a` コマンドを使用して起動するように改善。
        - `/Applications/Antigravity IDE.app`
        - `/Applications/Antigravity.app`
    - 以前はパッケージ内部の実行バイナリ（`Contents/MacOS/Electron`など）を直接起動していたため、Electronアプリとしての初期化やリソースの読み込みに失敗し、起動しない問題が発生していました。本修正により、macOS標準の安全な起動手段（`open` コマンド）を使用することで、確実にアプリが開くようになりました。

### キーボードショートカット
- **フォルダ作成**:
    - 左と真ん中のペインがアクティブ（フォーカスされている）状態で、修飾キーなしの `a` キーを押すとフォルダ作成ダイアログが開く。
- **検索ボックスフォーカス**:
    - `Ctrl/Cmd + F` または `/` キーでペイン内の検索ボックスに即時フォーカス。`Escape` でクリア＆一覧復帰。
- **左右同期移動**:
    - `Alt + S` キーで左右ペインの同期移動モードをON/OFFトグル。

### 画像ビューワー (`ImagePreviewModal`)
- **インライン画像配信**:
    - `GET /api/view-image?path=...` により、PNG, JPG, GIF, SVG, WEBP, BMP, ICO, AVIF を適切な Content-Type でインライン配信。
    - 日本語ファイル名の RFC 2231 エンコードに対応。
- **アプリ内プレビューモーダル**:
    - 画像ダブルクリック、Enter、または右クリック「画像を表示」で起動。
    - ズーム（拡大 `+`、縮小 `-`、等倍 `0`）、90度回転、同一フォルダ内の前後画像切り替え（`←` / `→`）、解像度・ファイルサイズ表示、ダウンロード、別タブ表示をサポート。

### 左右ペイン同期移動 (Synchronized Browsing)
- **連動移動ロジック**:
    - 同期モードON時、一方のペインでの移動（子フォルダへ進む、親フォルダへ戻る等）に合わせてもう一方のペインも連動して移動。
    - 左右が同一パスの場合は完全に一致して移動。左右が異なるパスの場合は相対サブフォルダや親フォルダに移動。
    - ヘッダー内の「同期移動」ボタンおよび「右ペインを左ペインに同期」ボタンから操作可能。設定は localStorage に保存。

### 検索ボックス強化
- **インクリメンタル検索 & ショートカット**:
    - `Ctrl/Cmd + F` または `/` で即時フォーカス。
    - `Enter` で次の検索ヒットへ移動、`Shift + Enter` で前の検索ヒットへ戻る（循環ラップアラウンド対応、入力欄フォーカス維持で連続移動可能）。
    - リアルタイム位置・件数表示バッジ（検索中は `現在位置 / ヒット数`、未検索時は `全件 / 全件`）。
    - 入力中のクリアボタン（`×`）、正規表現トグル（`.*`）を完備。
    - `Escape` キーでクエリをクリアし、ファイル一覧にフォーカスが戻る。

### Markdownビューワ・エディタの画像プレビュー表示
- **相対パス・絶対パス・Obsidian構文の自動解決**:
    - `![alt](image.png)` や `![alt](./sub/photo.jpg)` などのローカル相対パスを、対象Markdownファイルの親ディレクトリ（`baseDir`）を基準に絶対パスへ結合・解決。
    - バックエンドの画像インライン配信API（`GET /api/view-image?path=...`）を通じてプレビュー内に画像を直接描画。
    - Obsidian形式の画像埋め込み構文（`![[image.png]]`、幅指定 `![[image.png|300]]`、幅・高さ指定 `![[image.png|300x200]]`）にも完全対応。
    - 外部Web画像（`http://`, `https://`）および Data URI（`data:image/...`）もそのまま表示。
    - 画像の最大幅制限（`max-width: 100%`）により、大きな画像でもエディタ/プレビュー領域内に適切に収まるスタイリングを適用。
