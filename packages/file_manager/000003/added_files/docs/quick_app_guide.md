# Quick アプリ利用ガイド・仕様書

## 1. 概要
スマートフォンからのデータアクセス、検索、連絡先確認、簡易編集に特化した軽量Webアプリです。
ファイルマネージャー本体に影響を与えないよう、完全独立のフロントエンド（`frontend-quick/`）として構築され、FastAPIバックエンドの `/quick/` パスから配信されます。

![Quickアーキテクチャ図](quick_architecture.excalidraw)

## 2. 主な特徴・機能

### ① スマホ特化の検索・スニペット表示
- **インクリメンタル検索**: キーワードを入力するとリアルタイムにファイル名および本文（全文検索）を検索。
- **スニペットプレビュー**: 本文中に検索キーワードがヒットした場合、該当行とその前後のテキストをカード内にハイライト表示。
- **フィルタタブ**: 「すべて」「文書・メモ（.md, .txt）」「図面・画像（.svg, .drawio, .excalidraw）」のワンタップ切替。

### ② 連絡先クイックアクション（電話発信・コピー）
- ファイル閲覧時、本文中の電話番号（携帯、固定電話、フリーダイヤル）を自動検出。
- 画面上部の専用パネルから **「発信（tel:）」** ボタンをワンタップするだけで電話をかけられます。
- 番号コピーボタンも完備。

### ③ Markdown & 図面（画像・SVG・Excalidraw）のフルレンダリング表示
- **ファイルマネージャー本体準拠の美麗デザイン**:
  - 見出し（H1〜H6）: ネオングリーン（`#66ff69`）の発光シャドウ ＋ イエローの下線
  - 太字（`**bold**`）: 鮮やかなイエロー（`#ffff00`）
  - 箇条書き・タスクチェックボックス: イエローアクセント（`#ffee00`）
  - コードブロック: VS Code Dark+ 準拠のダークスタイル ＋ 言語ラベル
  - **GFMテーブル（表）**: ヘッダー（ネオングリーン背景）、微細ボーダー、ゼブラハイライト、セル内の太字・コード・リンク等の装飾反映、およびスマホ画面での横スクロール対応（`overflow-x: auto`）
- **リンクのスマート解決（URL自動リンク化 ＆ 同一タブ遷移 ＆ ローカルホスト対策）**:
  - **URL自動リンク化 (Autolink)**: 本文やテーブル内に記載された平文のURL（`https://forms.office.com/...` など、長大なクエリ付きURLや `<https://...>` 形式）を自動検知してクリック可能リンク化。
  - **同一タブ遷移（ブラウザの「戻る」対応）**: 別タブ（`target="_blank"`）ではなく同一タブで開くため、スマホのブラウザ標準の「戻る」ボタンやスワイプバックジェスチャーがそのまま利用可能。
  - 本文中に `http://localhost:...` や `http://127.0.0.1:...`（Excalidraw等）のリンクがある場合、設定されたTailscaleホスト名（`mineomacbook-air.taild3cb7c.ts.net`）へ自動置換して開きます。
  - 相対ファイルリンク（`[ノート](note.md)`）はQuickアプリ内で直接開きます。
  - Wikilink（`[[ノート名]]`）はタップ時に該当キーワードで即時検索します。
- **図面・画像インライン表示**:
  - 標準Markdown画像構文（`![alt](path)`）および相対パス画像を自動解決してインライン表示。
  - Obsidian画像埋め込み構文（`![[image.png]]`、サイズ指定 `![[image.png|300x200]]`）に完全対応。
  - `.svg`, `.drawio.svg` などの図面も鮮明に表示。
- **Excalidraw連携**: `.excalidraw` ファイルには、Tailscaleホスト対応の「Excalidrawで開く」リンクを提供。
- **表示切替（プレビュー ⇔ 生テキスト）**: ヘッダーのアイコンボタンで、レンダリング表示とプレーンテキスト表示をいつでもワンタップで切り替え可能。

### ④ URL履歴同期 ＆ ブラウザ戻る復帰
- ファイルを開いた際、ブラウザのURLクエリパラメータ（`/quick/?file=/path/to/note.md`）およびブラウザ履歴スタック（`history.pushState`）が自動同期されます。
- 外部リンク（Forms等）へ飛んだ後にブラウザの「戻る」ボタンで戻った場合、トップ画面ではなく**開いていたファイルがそのまま自動復元**されます。
- ブラウザの「戻る」「進む」操作やiOS/Androidのbfcache（進む戻るキャッシュ）にも完全対応。

### ⑤ スマホ最適化テキスト編集
- 閲覧画面からワンタップで「編集」モードへ移行。
- スマホのソフトキーボード入力に対応（フォントサイズ16pxで自動ズームを防止）。
- バックエンドの `/api/update-file` APIにより、端末内のファイルを即座に保存・更新。

### ⑤ Tailscale / 接続先ホスト設定
- 右上の歯車アイコン（⚙️）から、サーバーホスト名（Tailscaleドメイン `mineomacbook-air.taild3cb7c.ts.net` やローカルIP）、APIポート、Excalidrawポート、検索対象パス（`/Users/mine/000_work`）を自由に設定・保存可能。
- 設定は端末のブラウザ（localStorage）に永続化されます。

## 3. スマホからのアクセス方法

### 起動
```bash
./start.sh
```
バックエンド（8001ポート）が起動し、`frontend` および `frontend-quick` の両方がビルド・配信されます。

### アクセスURL
- **Quickアプリ（スマホ用）**:
  `http://mineomacbook-air.taild3cb7c.ts.net:8001/quick/`
  （※ローカル同一Wi-Fiの場合は `http://<MacのIP>:8001/quick/`）
- **ファイルマネージャー本体（PC用）**:
  `http://mineomacbook-air.taild3cb7c.ts.net:8001/`

### PWA（ホーム画面に追加）
1. スマホのSafari（iOS）またはChrome（Android）で上記QuickアプリのURLを開く。
2. 共有メニューから「ホーム画面に追加」をタップ。
3. ホーム画面に「Quick」アイコンが作成され、次回以降は全画面のネイティブアプリ感覚でワンタップ起動可能。

## 4. プロジェクト構成

```
file_manager/
├── backend/                  # FastAPI 共通バックエンド
│   ├── app/main.py           # /quick への静的配信・SPAフォールバック
│   └── tests/
│       └── test_quick_serving.py # 配信テスト
│
├── frontend/                 # ファイルマネージャー本体（変更なし）
│
└── frontend-quick/           # スマホ専用独立フロントエンド
    ├── src/
    │   ├── api/client.ts     # 動的ホスト対応APIクライアント
    │   ├── components/       # Header, SearchBar, FileViewer, FileEditor, SettingsModal
    │   ├── utils/            # config.ts, phone.ts
    │   ├── App.tsx
    │   └── index.css         # モバイルファーストCSS
    ├── package.json
    └── vite.config.ts        # base: '/quick/'
```
