# ファイルアイコン表示仕様

## 概要

本アプリケーションでは、ファイル一覧（`FileList`）およびファイル検索（`FileSearch`）において、Catppuccinアイコンセット（SVG）を使用して各拡張子・ファイル形式に応じたアイコンを表示しています。

## メールファイルアイコン対応

### 対象拡張子
- `.msg` (Outlook メッセージファイル)
- `.eml` (電子メールメッセージファイル)

### アイコン
- **アイコン名**: `mail`
- **画像パス**: `/icons/catppuccin/mail.svg`
- **デザイン**: 封筒形状のアイコン（Catppuccin blue: `#1E66F5`）

### 解決の流れ
1. ファイル名から拡張子を取得（小文字に正規化）
2. `extensionToIcon` マッピングテーブル（`frontend/src/utils/iconMapping.ts`）を参照
3. `msg` または `eml` の場合は `mail` が返却される
4. `/icons/catppuccin/mail.svg` の画像パスを組み立てて `FileIcon` コンポーネントが描画

```
+--------------------+      ext = "msg"      +---------------------+      "mail"      +------------------------------+
| sample.msg (File)  | --------------------> | extensionToIcon     | ---------------> | /icons/catppuccin/mail.svg   |
+--------------------+                       +---------------------+                  | (封筒アイコンが表示される)   |
                                                                                      +------------------------------+
```
