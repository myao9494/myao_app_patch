# 画像ビューワー仕様書 (Image Viewer)

## 概要
画像ファイル（`.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.svg`, `.bmp`, `.ico`, `.avif`）をアプリケーション内で高速・リッチにプレビュー閲覧する機能です。大画面モーダルによる高品質な画像閲覧、マウスホイールによるポインター中心のスムーズな拡大縮小、ドラッグによる自由なパン移動、実寸（1:1）や画面フィット、ダブルクリック切り替え、回転・反転、ピクセル補間（ドット強調）、ナビゲーションミニマップ、同一フォルダ内画像ナビゲーション、詳細メタデータ表示を提供します。

---

## 主な機能

1. **マウスホイールズーム（ポインター座標中心）**:
   - マウスホイールのスクロール（上: 拡大、下: 縮小）またはトラックパッドのピンチ操作で直感的にズームイン・ズームアウト。
   - カーソル直下の画像ピクセル位置が固定される滑らかな座標追従計算を採用。
   - 0.1倍（10%）〜 30倍（3000%）まで広範囲かつ滑らかに拡大縮小可能。

2. **ドラッグによる自由なパン移動（Pan / Drag）**:
   - Pointer Events API を用いて画像を掴んで自由にパン移動（`cursor: grab` / `grabbing`）。
   - ドラッグ操作と背景クリック（モーダルを閉じる）の誤認防止判定を完備。

3. **ダブルクリックでのズーム切り替え**:
   - 画像をダブルクリックすることで、「画面フィット」と「拡大（実寸または2倍）」を瞬時にトグル。

4. **実寸（1:1）表示 ＆ 画面フィット**:
   - 「1:1」ボタン: 画像の自然解像度（naturalWidth / naturalHeight）での等倍ピクセル表示。
   - 「フィット」ボタン: 画面全体に収まる初期表示（scale=1, offset=(0,0)）へリセット。
   - ズーム倍率ボタンをクリックすると、プリセット一覧（25%, 50%, 75%, 100%, 150%, 200%, 300%, 400%, 800%）からワンクリック選択可能。

5. **回転・反転・ピクセル補間**:
   - 90度回転（時計回り `R` / 反時計回り `Shift+R`）。
   - 水平反転（左右反転 `H`）および垂直反転（上下反転 `V`）。
   - ピクセル補間（`image-rendering: pixelated`、ショートカット `P`）: ドット絵、微細アイコン、PNGスクリーンショットをぼやけずに鮮明に拡大表示。

6. **ナビゲーションミニマップ（拡大時ナビゲーター）**:
   - ズーム時（1.05倍超）、画面右下に画像全体と現在の表示領域（青いハイライト矩形）を表示。
   - ミニマップ上のクリックやドラッグにより、見たい位置へ瞬時に視点を移動可能。

7. **フォルダ内画像ナビゲーション**:
   - 同一フォルダ内の画像一覧を自動検出し、前後の画像へワンクリックまたは矢印キー（`←` / `→`）でスムーズ遷移。
   - カウンター表示（例: `3 / 12`）。

8. **ダークモード／ライトモード完全対応 & アイコン視認性保護**:
   - `[data-theme="dark"]` / `[data-theme="light"]` に完全連動。
   - SVGアイコンの `fill: none` および `stroke: currentColor`、文字色を厳格に保護。
   - グローバルな `button` スタイルの汚染を遮断し、ダークモード時でも文字やアイコンが黒く塗りつぶされることなく、クリアで高コントラストな白色で表示。

9. **操作中の誤クローズ防止（明示的な終了操作のみ受付）**:
   - 画像表示領域、コントロール、ミニマップ等の操作中にイベントバブリングを遮断し、クリックやドラッグ操作でモーダルが勝手に閉じる不具合を根絶。
   - モーダルが閉じる条件を「エスケープキー」「右上の×ボタン」「モーダル外側の直接暗幕クリック」に限定。

10. **複数画像グリッド表示（Grid View）**:
   - フォルダ内の全画像ファイルをサムネイルカードでタイル状に一覧表示。
   - サムネイルサイズ切り替え（「小」「中」「大」ボタン）で最適な密度に調整可能。
   - 各カードにはサムネイル画像（遅延読み込み `loading="lazy"`）、ファイル名、ファイルサイズを表示。
   - サムネイルをクリックすると、該当画像の「単一画像プレビュー」へ即座に展開。
   - 単一表示モードの上部ツールバーに「グリッド表示」ボタン（`LayoutGrid`）を配置し、ワンクリックまたはショートカットキー `G` で相互に切り替え可能。

11. **右クリックメニューからの「画像を表示」起動**:
   - **ペイン背景・ヘッダー（PaneContextMenu）**: 余白やヘッダーを右クリックして「画像を表示」を選択すると、現在フォルダ内の全画像を対象にグリッド表示で起動。
   - **アイテム行（ContextMenu）**: ファイルやフォルダの右クリックメニューから「画像を表示」を選択可能。
   - フォルダ内に画像が1枚も存在しない場合は、「このフォルダ内に画像ファイルはありません」という親切なトースト通知を表示。

12. **クリップボードに保存（コピー）機能**:
   - ツールバーの「クリップボードに保存」ボタンまたはショートカット `Ctrl+C` / `Cmd+C` で、画像をクリップボードに直接コピー。
   - ブラウザの Clipboard API（`navigator.clipboard.write`）を利用し、PNG画像またはCanvas経由変換したPNG Blobとしてコピーされるため、Slack、Discord、Obsidian、Word、Excel等に直接 `Cmd/Ctrl + V` で貼り付け可能。
   - コピー完了時はボタンがチェックマーク（緑色）に変化し、トースト通知を表示。

13. **詳細メタデータ & ユーティリティ**:
   - ファイル名、自然解像度（幅 × 高さ px）、アスペクト比（例: `16:9`, `4:3`, `1:1`）、ファイルサイズを表示。
   - ダウンロード、ブラウザの別タブで開く機能、フルスクリーン表示（`F`）。

14. **キーボードショートカット**:
   - `Escape`: プレビューを閉じる
   - `G`: グリッド表示 ⇔ 単一表示のトグル
   - `Ctrl+C` / `⌘C`: 画像をクリップボードに保存（コピー）
   - `ホイール`: カーソル位置を中心にズームイン/アウト
   - `ドラッグ`: 画像のパン移動
   - `ダブルクリック`: フィット ⇔ 拡大の切り替え
   - `←` / `→`: 前の画像 / 次の画像
   - `+` / `=`: 拡大
   - `-`: 縮小
   - `0`: 画面フィット (リセット)
   - `1`: 実寸等倍 (1:1 100%)
   - `R` / `Shift+R`: 時計回り / 反時計回りに90°回転
   - `H` / `V`: 左右反転 / 上下反転
   - `P`: ピクセル補間（ドット強調）切替
   - `F`: フルスクリーントグル
