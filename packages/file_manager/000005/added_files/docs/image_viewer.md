# 画像ビューワー仕様書 (Image Viewer)

## 概要
画像ファイル（`.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.svg`, `.bmp`, `.ico`, `.avif`）をアプリケーション内で高速・リッチにプレビュー閲覧する機能です。大画面モーダルによる高品質な画像閲覧、マウスホイールによるポインター中心のスムーズな拡大縮小、ドラッグによる自由なパン移動、実寸（1:1）や画面フィット、ダブルクリック切り替え、回転・反転、ピクセル補間（ドット強調）、ナビゲーションミニマップ、同一フォルダ内画像ナビゲーション、詳細メタデータ表示を提供します。

---

## 主な機能

1. **マウスホイールズーム（ポインター座標中心）**:
   - マウスホイールのスクロール（上: 拡大、下: 縮小）またはトラックパッドのピンチ操作で直感的にズームイン・ズームアウト。
   - カーソル直下の画像ピクセル位置が固定される滑らかな座標追従計算を採用。
   - 0.1倍（10%）〜 30倍（3000%）まで広範囲かつ滑らかに拡大縮小可能。

2. **ドラッグによる自由なパン移動（Pan / Drag）**:
   - Pointer Events API を用いて画像を掴んで自由にパン移動（`cursor: grab` / `grabbing`）。
   - ドラッグ操作と背景クリック（モーダルを閉じる）の誤認防止判定を完備。

3. **ダブルクリックでのズーム切り替え**:
   - 画像をダブルクリックすることで、「画面フィット」と「拡大（実寸または2倍）」を瞬時にトグル。

4. **実寸（1:1）表示 ＆ 画面フィット**:
   - 「1:1」ボタン: 画像の自然解像度（naturalWidth / naturalHeight）での等倍ピクセル表示。
   - 「フィット」ボタン: 画面全体に収まる初期表示（scale=1, offset=(0,0)）へリセット。
   - ズーム倍率ボタンをクリックすると、プリセット一覧（25%, 50%, 75%, 100%, 150%, 200%, 300%, 400%, 800%）からワンクリック選択可能。

5. **回転・反転・ピクセル補間**:
   - 90度回転（時計回り `R` / 反時計回り `Shift+R`）。
   - 水平反転（左右反転 `H`）および垂直反転（上下反転 `V`）。
   - ピクセル補間（`image-rendering: pixelated`、ショートカット `P`）: ドット絵、微細アイコン、PNGスクリーンショットをぼやけずに鮮明に拡大表示。

6. **ナビゲーションミニマップ（拡大時ナビゲーター）**:
   - ズーム時（1.05倍超）、画面右下に画像全体と現在の表示領域（青いハイライト矩形）を表示。
   - ミニマップ上のクリックやドラッグにより、見たい位置へ瞬時に視点を移動可能。

7. **フォルダ内画像ナビゲーション**:
   - 同一フォルダ内の画像一覧を自動検出し、前後の画像へワンクリックまたは矢印キー（`←` / `→`）でスムーズ遷移。
   - カウンター表示（例: `3 / 12`）。

8. **ダークモード／ライトモード完全対応 & アイコン視認性保護**:
   - `[data-theme="dark"]` / `[data-theme="light"]` に完全連動。
   - SVGアイコンの `fill: none` および `stroke: currentColor`、文字色を厳格に保護。
   - グローバルな `button` スタイルの汚染を遮断し、ダークモード時でも文字やアイコンが黒く塗りつぶされることなく、クリアで高コントラストな白色で表示。

9. **操作中の誤クローズ防止（明示的な終了操作のみ受付）**:
   - 画像表示領域、コントロール、ミニマップ等の操作中にイベントバブリングを遮断し、クリックやドラッグ操作でモーダルが勝手に閉じる不具合を根絶。
   - モーダルが閉じる条件を「エスケープキー」「右上の×ボタン」「モーダル外側の直接暗幕クリック」に限定。

10. **複数画像グリッド表示（Grid View）**:
   - フォルダ内の全画像ファイルをサムネイルカードでタイル状に一覧表示。
   - サムネイルサイズ切り替え（「小」「中」「大」ボタン）で最適な密度に調整可能。
   - 各カードにはサムネイル画像（遅延読み込み `loading="lazy"`）、ファイル名、ファイルサイズを表示。
   - サムネイルをクリックすると、該当画像の「単一画像プレビュー」へ即座に展開。
   - 単一表示モードの上部ツールバーに「グリッド表示」ボタン（`LayoutGrid`）を配置し、ワンクリックまたはショートカットキー `G` で相互に切り替え可能。

11. **右クリックメニューからの「画像を表示」起動**:
   - **ペイン背景・ヘッダー（PaneContextMenu）**: 余白やヘッダーを右クリックして「画像を表示」を選択すると、現在フォルダ内の全画像を対象にグリッド表示で起動。
   - **アイテム行（ContextMenu）**: ファイルやフォルダの右クリックメニューから「画像を表示」を選択可能。
   - フォルダ内に画像が1枚も存在しない場合は、「このフォルダ内に画像ファイルはありません」という親切なトースト通知を表示。

12. **クリップボードに保存（コピー）機能**:
   - ツールバーの「クリップボードに保存」ボタンまたはショートカット `Ctrl+C` / `Cmd+C` で、画像をクリップボードに直接コピー。
   - ブラウザの Clipboard API（`navigator.clipboard.write`）を利用し、PNG画像またはCanvas経由変換したPNG Blobとしてコピーされるため、Slack、Discord、Obsidian、Word、Excel等に直接 `Cmd/Ctrl + V` で貼り付け可能。
   - コピー完了時はボタンがチェックマーク（緑色）に変化し、トースト通知を表示。

13. **高解像度レンダリング（自然解像度基準・文字ボケ防止）**:
   - PNG, JPG, SVG, WebP, AVIF, GIF, BMP 等のテキスト・図面画像において、文字や細い線がぼやけて読めなくなる問題を根本解消。
   - `naturalSize`（画像本来の解像度）に基づき、ビューポート枠内に収まる最適な基準フィットサイズ（`baseFitSize`）を動的に算出して `img` 要素に適用。
   - 実寸（1:1 100%）表示やズーム時も自然解像度を基準にスケール計算を行い、静止時にブラウザが最高品質で再ラスタライズできるよう `will-change: transform` をドラッグ中のみに限定。
   - CSS に `image-rendering: -webkit-optimize-contrast; image-rendering: high-quality; image-rendering: auto;` を指定し、文字の輪郭やベクター描画を極めて鮮明にくっきり描画。

14. **グリッド上下左右選択移動 & リターンキー（Enter）展開**:
   - **2次元グリッド選択（上下左右）**: グリッド表示時、`←` / `→` の左右だけでなく、`↑` / `↓` の上下矢印キーでもコンテナ幅・サムネイルサイズから動的に算出した列数（columns）に応じて上下のカードへ正確に移動可能。
   - **親再描画の遮断による超爆速レスポンス**: グリッド選択移動中は親コンポーネント（FileList）の再レンダリングをトリガーせず、モーダルローカルでカード選択を即座に更新。キー入力の遅延・もっさり感を完全に根絶。
   - **視覚的強調 & 即時スクロール追従**: 選択中のカード（`.grid-card.selected`）には高コントラストな青枠とグローシャドウが付与され、矢印キーで画面外へ移動した際も `scrollIntoView({ behavior: "auto" })` によりキュー遅延なく即時に追従。
   - **Enter / Return キーでの展開**: 選択状態でリターンキー（Enter）またはサムネイルクリックにより、即座に該当画像を単一画像プレビュー（拡大プレビュー）として展開。
   - **前後画像プリロードによる高速プレビュー切り替え**: 単一プレビュー表示中、前後の画像をバックグラウンドで事前読み込み（Image preloading）。矢印キー（`←` / `→` / `↑` / `↓`）を押した瞬間に0msで次の画像へシームレスに切り替わり、プレビュー画面状態を維持したまま快適に閲覧可能。
   - **バックエンドHTTPキャッシュ**: `/api/view-image` に `Cache-Control: public, max-age=86400` を付与し、同一セッション内の無駄なネットワーク通信・ディスクI/Oを排除。

15. **フォーカス自動制御＆キー連打安定化（キーボード即時反応保証・1回即移動）**:
   - **背後要素フォーカス残存の完全排除**:
     - モーダルが開いた際、背後のパス入力欄（`<textarea>`）や検索バー（`<input>`）にフォーカスが残ったままになっていると、キーイベントハンドラーのフォーム入力保護ガードにより全キー入力がスキップされてしまう問題（マウスクリックするまで反応しない・動く時と動かない時がある現象）を根本解消。
     - モーダルオーバーレイ要素（`.image-preview-overlay`）に `tabIndex={-1}` を設定し、モーダル展開時に `document.activeElement.blur()` を実行した上で `requestAnimationFrame` によりモーダル自身に確実にフォーカスを当てる。
     - `keydown` イベント受信時にも、フォーカスがモーダル外（背後）に残っていた場合は即時 `blur()` してモーダルの操作キーとして処理を継続するフェイルセーフを完備。
   - **1回のキー入力での確実な即時移動（リバウンド引き戻し根絶）**:
     - 矢印キーを押した際、`selectedGridIndexRef.current` を即時インクリメント/デクリメントし、1回のキー押下で確実に1画像（グリッド時は1カード）移動。
     - モーダルが開いている間はモーダル内部の状態を単一の真実（Source of Truth）として自律更新。親コンポーネントの古いpropsや再レンダリングによる状態巻き戻し（リバウンド）を根絶。
     - モーダルが処理したキーイベントに `e.stopPropagation()` を適用し、背後のFileListにキーイベントが漏れて二重処理されることを遮断。
   - **画像リストのキャッシュ化（親再描画抑止）**:
     - `FileList.tsx` 側で `currentFolderImages` を `useMemo` でキャッシュ化し、毎レンダリングでの不要な配列生成と `useEffect` の無駄な再実行を完全に抑止。

16. **単一プレビューから上キー（ArrowUp）でのグリッド表示復帰**:
   - 単一画像プレビュー（拡大プレビュー）表示中に上矢印キー（`↑` / `ArrowUp`）を押すと、即座にフォルダ内ファイルのグリッド表示に戻る（`setViewMode("grid")`）。
   - 今閲覧していた画像のインデックスと選択状態がグリッド上でそのまま保持され、`scrollIntoView` により該当カードへスクロール位置も自動追従。

17. **階層指定（depth）によるサブフォルダ画像の一覧表示**:
   - グリッド表示上部のヘッダーに階層指定ステッパー（`[-] 階層: X [+]`）を配置。
   - **初期値**: `0`（指定フォルダ直下の画像のみ表示）。
   - **階層指定（0〜10）**: `+` ボタンで階層を深くすると、バックエンドの高速収集API（`GET /api/folder-images?path=...&depth=...`）を自動呼び出し、サブフォルダ内の画像もすべてフラットに一覧化。
   - **高速・安全な走査**: Pythonの `os.scandir` による高速ディレクトリトラバース。`.git` や `node_modules` などのシステム/巨大ディレクトリは自動除外。
   - **相対パス表示**: サブフォルダ内の画像カードには、親フォルダからの相対パス（例: `subfolder/image.png`）がバッジおよびサブテキストとして表示され、どの階層の画像かひと目で確認可能。
   - **単一プレビューとの連動**: 階層探索で取得された画像リストは単一プレビュー時にも共有され、矢印キー（`←` / `→`）でサブフォルダ内の画像も含めて連続ナビゲーションが可能。

18. **詳細メタデータ & ユーティリティ**:
   - ファイル名、自然解像度（幅 × 高さ px）、アスペクト比（例: `16:9`, `4:3`, `1:1`）、ファイルサイズを表示。
   - ダウンロード、ブラウザの別タブで開く機能、フルスクリーン表示（`F`）。

19. **キーボードショートカット**:
   - `Escape`: プレビューを閉じる
   - `G`: グリッド表示 ⇔ 単一表示のトグル
   - `↑`（単一プレビュー時）: フォルダ内ファイルのグリッド表示に戻る
   - `←` / `→`（単一プレビュー時）: 前後の画像へ切り替え
   - `↑` / `↓` / `←` / `→`（グリッド表示時）: カード選択移動
   - `Enter` / `Return`（グリッド表示時）: 選択画像を単一プレビュー（拡大プレビュー）で開く
   - `Ctrl+C` / `⌘C`: 画像をクリップボードに保存（コピー）
   - `ホイール`: カーソル位置を中心にズームイン/アウト
   - `ドラッグ`: 画像のパン移動
   - `ダブルクリック`: フィット ⇔ 拡大の切り替え
   - `+` / `=`: 拡大
   - `-`: 縮小
   - `0`: 画面フィット (リセット)
   - `1`: 実寸等倍 (1:1 100%)
   - `R` / `Shift+R`: 時計回り / 反時計回りに90°回転
   - `H` / `V`: 左右反転 / 上下反転
   - `P`: ピクセル補間（ドット強調）切替
   - `F`: フルスクリーントグル
