# 外部アプリ・サービス依存

このアプリは、本番時にFastAPI（port 3001）がPWAとAPIを同一オリジンで配信します。描画、ローカルファイルの読み書き、バックアップは、このリポジトリだけで動作します。

## 必須ランタイム

- 対応ブラウザー: PWA、Service Worker、Clipboard APIを利用します。
- Python / FastAPI: ローカルファイルI/OとOS連携を担当します。
- Node.js / npm: フロントエンドのビルドに使用します。ビルド済みの `dist/` を git 管理しているため、ビルドできない環境（社内PCなど）では不要です（起動スクリプトが自動で `dist/` を使います）。
- OS標準オープナー: macOSの `open`、Windowsの既定アプリ、Linuxの `xdg-open` を使用します。

ブラウザーを別PCから接続した場合、ファイル操作と「OSで開く」はブラウザー側ではなく、FastAPIを実行しているPC上で行われます。

## 任意の連携

| 連携先 | 使用箇所 | 未導入・未起動時の動作 |
|---|---|---|
| port 8001 リダイレクトサービス | Excalidraw以外の付箋リンク、`filepath` で渡された一般ファイル、フォルダーを開く操作 | 同梱FastAPIの `/api/open-file` を使い、OSの既定アプリで開く |
| Visual Studio Code | ヘッダーの「codeで開く」 | OS標準のファイルマネージャーで対象フォルダーを開く |
| Obsidian | `obsidian://` リンク | 起動に失敗したことを画面に通知する。`.excalidraw.md` の読み書き自体はObsidianなしでも利用可能 |
| Outlook | Outlookからのメール直接ドロップ | Outlook固有の直接ドロップだけ利用不可。`.eml` / `.msg` ファイルのドロップは継続して利用可能 |
| Tailscale | 別端末からのアクセス | 任意。LANやlocalhostでも利用可能 |

port 8001の既定URLは `http://<PWAと同じホスト>:8001` です。別URLを使う場合はビルド時に `VITE_REDIRECT_SERVICE_URL` を指定します。

## 外部ネットワーク

Excalidraw本体、フォント、画像アセットはビルドまたは `public/` に含まれます。通常動作にCDNは不要です。付箋に設定した通常のHTTP/HTTPS URLを開く場合だけ、そのリンク先へのネットワーク接続が必要です。

## 配布時のセキュリティ注意

バックエンドには任意パスの読み書き、OSで開く処理、コマンド実行APIがあります。起動スクリプトは `0.0.0.0` で待ち受けるため、信頼できる端末・LAN・VPN内だけで利用し、インターネットへ直接公開しないでください。
