# 変更履歴

- **2026/03/09**: 
  - `sw.js`: キャッシュ戦略を修正し、POSTリクエスト時に `caches.put` を実行しないように制限しました。
  - `index.html`: `<meta name="apple-mobile-web-app-capable" content="yes">` の非推奨警告（Deprecated warning）を解消するため、標準の `<meta name="mobile-web-app-capable" content="yes" />` を追加しました。

- **2026/06/03**:
  - `@excalidraw/excalidraw` を 0.18.1 にアップデートしました。
  - フロントエンド・バックエンドの依存ライブラリ（React, Vite, FastAPI, Pydantic, Uvicorn等）を新バージョンに更新し、ビルドおよびテストが正常に通ることを検証しました。

- **2026/08/10**（コードレビュー）:
  - port 5001の廃止済みファイルビューアー依存を削除し、PWA内蔵ファイルブラウザーへ統合。
  - port 8001は任意のリダイレクトサービスとして優先し、未起動時は同梱FastAPIからOS標準アプリで開くよう統一。
  - VS Codeがない環境で「codeで開く」を押した場合、ファイルマネージャーを開くフォールバックを追加。
  - 開発時にViteとFastAPIが同じport 3001を取り合う構成を、Vite 3001 / FastAPI 8008 + proxyへ修正。本番PWAはFastAPI 3001の単一配信を維持。
  - 空キャンバスを保存できず、全要素削除後も古い内容が残る問題を修正。
  - `.excalidraw.md` をフォルダー名に依存せず読み書きできるよう修正。
  - URLパラメーターの二重デコードを除去し、`%` を含む正当なファイル名の破損を防止。
  - Service Workerが画像等のレスポンスを `/` のアプリシェルとして保存し得るキャッシュキー不具合を修正。
  - ライブラリ保存とアップロードファイル配信のパストラバーサルを制限し、外部URLスキームを許可リスト化。
  - Pydanticの可変デフォルト、FastAPIの非推奨startupイベント、Excalidraw 0.18.1に追従していないTypeScript型を修正。
  - port判定を待受プロセスだけに限定。本番の `start_servers.sh` は再実行時にport 3001の旧待受をTERMで終了し、終了しない場合だけKILLして再起動。開発スクリプトは無関係なプロセスを自動終了しない。
  - 旧 `.excalidraw`、非圧縮 `.excalidraw.md`、独自Front Matter・追加メモ、Embedded Files画像の保存互換性テストを追加。旧 `json` フェンス保存時は図面ブロックだけを正式な `compressed-json` へ正規化し、未知のトップレベル項目も保存時に維持。
  - 通常ファイル・Obsidian Markdown・埋め込み画像を原子的に置換し、途中失敗による切り詰めを防止。同秒の強制バックアップには連番を付けて上書きを防止。
  - 壊れたDrawingセクションの後にある業務メモのJSONを図面と誤認しないようMarkdown境界判定を厳密化。
  - 起動スクリプトはプロセス開始だけで成功扱いにせず、port 3001のHTTP応答を確認してから起動完了を表示。
  - Windows版は空白を含むパスを正しく引用し、一般的な4種類のvenv配置、Python依存確認、待受解放待ち、PowerShellによるHTTP readinessを追加。Windows固有のOSオープナー・Explorer・コマンド起動・バッチ契約を自動テスト化。
  - 実体のないPythonユーティリティを参照していた古いテストを整理し、ライブサーバーテストを明示的なopt-inに変更。

- **2026/08/28**:
  - Obsidian外に移動したフォルダ内の `.excalidraw.md` ファイルにおいて、画像リンク（`[[attachments/xxx.png]]` 等）が切れてしまう問題を解決しました。
  - バックエンドの画像解決処理（`resolve_embedded_file_path` / `parse_embedded_files_section`）を強化し、同一フォルダ直下およびサブフォルダ内の画像自動検出、URLデコード、拡張子補完、パイプ除去、Case-insensitive探索をサポートしました。

- **2026/09/04**:
  - ショートカットキー「M」によるマーカー（テキストハイライト）機能を追加しました。
  - テキスト要素選択時に「M」キーを押すと、文字の下半分に淡い黄色の手書き風マーカー帯（長方形、透明度50%）を自動生成して背面に配置・グループ化します（再押下でトグル解除）。
  - 未選択時に「M」キーを押すと、マーカー矩形描画ツール（枠線なし、淡い黄色 `#fef08a`、透明度50%）が起動します。ドラッグしてマーカー矩形を描画でき、文字の上に重なった場合は自動的に文字の直前（背面）に配置されグループ化されます（描画完了後は元の描画スタイルが自動復元されます）。
  - ショートカットキー「U」によるアンダーライン（赤色下線）機能を追加しました。
  - テキスト要素選択時に「U」キーを押すと、文字の下端に赤色の直線下線（太さ2px、`#e03131`）を自動生成してグループ化します（再押下でトグル解除）。
  - 未選択時に「U」キーを押すと、赤色の直線描画ツール（`line`）が起動します。ドラッグして赤色下線を描画でき、文字と近接・重なった場合は自動的に文字とグループ化されます。描画終了後は直前の描画スタイル（文字色・枠線色・太さ・透明度等）が自動的に元通り復元されます。
  - ヘッダーメニューから不要な2ボタン（「ファイルを開く」「フォルダを表示」）を削除し、代わりに「マーカーとアンダーラインの設定」ボタンを追加しました。
  - ショートカットキー「,（カンマ）」により、マーカーとアンダーラインの設定パネルをいつでも開閉可能にしました。
  - マーカー（色、透明度）およびアンダーライン（色、線の太さ、透明度）の自由なカスタマイズおよびlocalStorageへの永続化、ショートカットM/Uへの即座の動的反映をサポートしました。
