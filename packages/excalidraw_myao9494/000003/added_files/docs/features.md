# 機能仕様

Excalidraw 0.18 に、ローカルファイルとの同期・独自ショートカット・付箋・ドラッグ&ドロップ・
Obsidian 互換を加えたアプリ。ここに書いた動作がコードの仕様（変更したらこの文書も更新する）。

## 1. ファイルを開く

- URL の `?filepath=<パス>` で開く図面を指定する（例: `http://localhost:3001/?filepath=/Users/me/memo.excalidraw`）
- 対応: `.excalidraw`、`.excalidraw.md`、Front Matter に `excalidraw-plugin: parsed` を持つ通常の `.md`
- それ以外のファイルを指定した場合は、OS の既定アプリで開く（[5. リンク](#5-図形リンク) と同じ方法）。
  その後の画面は localStorage モードになる
- `filepath` がない場合は **localStorage モード**（ブラウザ内に保存）
- 存在しないファイルを指定した場合は空の図面で始め、編集すると新規作成される
- 読み込めないファイル（JSON 不正など）は、エラー内容（行・列・前後の行）を通知し、
  **そのタブでは保存しない**（空の図面で上書きしないため）
- タブのタイトルは「ファイル名-親フォルダ-その親」（例: `top-personal-excalidraw_myao9494`）
- 起動時に共有ライブラリ `public/excalidraw_lib/my_lib.excalidrawlib` を読み込む

### Obsidian Vault 内の `.excalidraw`

Vault 内（祖先に `.obsidian/` がある）またはパスに `obsidian` を含む `.excalidraw` を開くと、
同じ内容で `<名前>.excalidraw.md` を作り、そちらを開き直す（URL も変わる）。
元の `.excalidraw` は `backup/<名前>_<日時>.excalidraw` に移動する。
既に `.excalidraw.md` がある場合はそちらを開く。詳細は [obsidian.md](obsidian.md)。

## 2. 保存

### 自動保存

- 図形を変更してから **10 秒後** に保存する。10 秒以内の変更はまとめて 1 回で保存する
- 内容が保存済みと同じなら保存しない。スクロール・ズーム・選択だけでは保存しない
  （保存時には、そのときのスクロール位置・ズーム・描画スタイルも一緒に保存される）
- 比較する内容: 要素の追加・削除、位置・サイズ・回転、線や塗りのスタイル、角丸、
  テキスト・文字サイズ・フォント・揃え、線の頂点・矢じり、リンク、グループ、ロック、画像、重なり順
- タブを切り替える・閉じるなどでタブが非表示になったら、保存待ちの変更をすぐに保存する
- 保存に失敗すると、右上に赤い通知を 10 秒表示する

### 手動保存

`Cmd/Ctrl + S` またはヘッダーの保存ボタン。内容が同じでも保存し、必ずバックアップを作る。
成功すると「保存しました」と表示する。

### 保存形式

| ファイル | 形式 |
| --- | --- |
| `.excalidraw`（Vault 内を含む） | Excalidraw 標準の JSON（インデント付き） |
| `.excalidraw.md`・parsed な `.md` | Obsidian 形式。本文・Front Matter は維持し、図面データ・Text Elements・Embedded Files だけを更新。画像は外部ファイルに書き出す |
| localStorage モード | ブラウザの localStorage（要素・画像・appState） |

### バックアップ（`.excalidraw` のみ）

保存前に、既存ファイルを同じフォルダの `backup/<名前>_backup_YYYYMMDD_HHMMSS.excalidraw` にコピーする。

- 自動保存では、直近 10 分以内にバックアップがあれば作らない
- 手動保存・外部更新の取り込み時は必ず作る
- 2 週間より古いバックアップは削除する。今日以外の日は、その日の最新 1 件だけを残す
- バックアップに失敗しても保存は続ける

## 3. 外部更新（別タブ・Obsidian・他の人による更新）

- 編集中は最短 5 秒ごと、保存の直前には毎回、ファイルの更新日時を確認する
- 前回の読み込み・保存より新しければ、**最新の内容を読み込んで画面を置き換え**、
  バックアップ付きで保存し直し、「最新の内容を読み込んで保存しました」と通知する
  （その時点でまだ保存していなかった自分の変更は、最新の内容で置き換わる）
- 自分の保存による更新日時の変化は外部更新とみなさない

## 4. キーボードショートカット

入力欄にフォーカスがあるときは無効。詳細は [shortcuts.md](shortcuts.md)、
マーカー・下線は [marker_feature.md](marker_feature.md)・[underline_feature.md](underline_feature.md)・
[annotation_settings.md](annotation_settings.md)。

| キー | 動作 |
| --- | --- |
| `.` | ショートカット一覧の表示・非表示 |
| `,` | マーカーとアンダーラインの設定パネル |
| `C` | 矢印ツールに切り替え、次に描いた矢印の矢じりを消す（矢印なしの直線）。チェックモード中はチェックマークの連続配置 |
| `N` | マウス位置に付箋（黄色、300×100、「メモを入力」）を作り、テキストを選択状態にする |
| `W` | クリップボードのパス・URL からリンク付き付箋を作る（表示はファイル名）。`.py` は `cmd python <パス>`、`.sh`/`.bat` は `cmd <パス>` をリンクにする |
| `M` | マーカー（テキスト選択時は付与/解除、未選択時はマーカー用の矩形ツール） |
| `U` | アンダーライン（テキスト選択時は付与/解除、未選択時は下線用の直線ツール） |
| `Tab` | 選択した図形を 四角形 → ひし形 → 円 の順に変える |
| `Cmd/Ctrl + S` | 手動保存 |
| `Cmd/Ctrl + M` | 選択要素（と結び付いたテキスト・矢印）を最前面へ |
| `Cmd/Ctrl + B` | 選択要素（と結び付いたテキスト・矢印）を最背面へ |
| `Option/Alt + C` | チェックモードのオン / オフ（下記） |

`C` / `M` / `U` で描画ツールに切り替えた後、描かずに別のツールへ切り替えた場合は後処理を取り消し、
`M` / `U` で変えた描画スタイルも元に戻す。

### チェックモード

画像を貼り付けて内容を確認していく（図面チェック）ためのモード。ヘッダー左端のチェックボタン、
または `Option/Alt + C` でオン / オフを切り替える（オンの間はボタンが赤くなり、通知も出る）。
状態は保存せず、起動・リロードのたびにオフから始まる。

| キー | チェックモードがオンのときの動作 |
| --- | --- |
| `M` | マーカーの矩形ツールを**固定**して起動。Esc かチェックモードをオフにするまで、描き終えるたびに続けて引ける（通常モードは 1 本引くと終わる） |
| `U` | 下線の直線ツールを同様に固定して起動。連続で引ける |
| `C` | 矢印なし直線の代わりに、図面を**クリックした位置にチェックマーク（✓、赤・3px の折れ線）を置く**ツール。連続で置ける |

- 連続描画の終了: `Esc` で別のツールへ切り替える / チェックモードをオフにする。終了時に描画スタイルと
  「ツールを固定」の状態は元に戻る
- 選択中のテキストへの `M` / `U`（付与・解除）は通常モードと同じ
- 他の連続描画への切り替え（`M` → `U` → `C` など）は、描画スタイルを最初の状態に戻したうえで切り替わる
- **ダブルクリックはテキスト編集を優先する**: 連続描画の途中でダブルクリックすると、1 回目・2 回目のクリックで
  生まれた線・矩形・チェックマークを取り消して連続描画を終え、選択ツールのときと同じ
  ダブルクリック（テキストの編集、空白なら新規テキスト）を行う。編集後は `M` / `U` / `C` を押し直す
- ドラッグせずクリックだけで生まれた線・矩形は、マーカー・下線として扱わない（グループ化しない）
- **描画色（文字・線の色）**: オンにした時点で赤（`#e03131`）に強制する。その後ユーザーが色を変えたらその色のまま、
  オフにしたら黒（`#1e1e1e`）に戻し、以降は自由に変えられる（起動直後のオフでは何もしない）。
  Excalidraw に文字だけの色設定はなく描画色は図形・線と共通のため、これから作る図形・線も同じ色になる。
  すでにある要素と付箋（`N` / `W`）の色は変えない

## 5. 図形リンク

リンクを設定した図形（付箋など）をクリックしたときの動作。相対パスは開いている図面のフォルダ基準。

| リンク | 動作 |
| --- | --- |
| `cmd <コマンド>` | サーバー PC でコマンドを実行（作業フォルダ = 図面のフォルダ）。`&quot;` は `"` に戻す |
| `obsidian://...` | OS の URL ハンドラーで開く（Obsidian が起動） |
| `http://` / `https://` | 新しいタブで開く |
| `.excalidraw` / `.excalidraw.md` | このアプリの新しいタブで開く |
| その他のファイル・フォルダ | port 8001 のリダイレクトサービスが動いていればそれを使い、なければ OS の既定アプリで開く |

## 6. ドラッグ&ドロップ

複数のファイル・フォルダをまとめてドロップできる。保存先は図面のフォルダの `uploads/`
（localStorage モードではプロジェクトの `upload_local/`）。詳細は [api.md](api.md#ドラッグドロップ)。

| ドロップしたもの | 結果 |
| --- | --- |
| 画像 | 図面に画像として貼る（長辺 400px まで縮小） |
| 一般ファイル | `uploads/files/` に保存し、リンク付き付箋（黄、200×50） |
| `.eml` / `.msg` | `uploads/emails/` に保存し、件名のリンク付き付箋（青） |
| フォルダ | `uploads/folders/` にパスを書いたショートカット(.txt)を作り、リンク付き付箋 |
| Outlook のメール | 本文を `.eml` として保存し、件名の付箋（青） |
| Web ページのリンク（http / https） | **何も保存せず**、URL をそのままリンクにした付箋（青）。表示テキストは従来どおりリンクの文字列（取れなければ URL）。クリックするとそのページが新しいタブで開く |

付箋の表示名は 25 文字を超えると省略する。

## 7. ヘッダーボタン（左上）

| ボタン | 動作 |
| --- | --- |
| ✓ チェックモード | チェックモードのオン / オフ（`Option/Alt + C`）。オンの間は赤く表示 |
| ＋ 新規作成 | ファイル名を入力し、開いている図面と同じフォルダにテンプレート（`shoki.excalidraw`）から `.excalidraw` を作って新しいタブで開く |
| ペン | マーカーとアンダーラインの設定（`,`） |
| キーボード | ショートカット一覧（`.`） |
| フォルダ | 図面のフォルダを開く（8001 → OS のファイルマネージャー） |
| `</>` | 図面のフォルダを VS Code で開く。なければファイルマネージャー |
| 保存 | 手動保存（バックアップ付き） |
| svg | 選択要素（未選択なら全体）を、ファイル名を入力して図面のフォルダに SVG で保存。選択した図形に結び付いたテキストも含め、図形のリンクはテキストにも付けてクリックしやすくする |

## 8. Obsidian ノートの埋め込み

Obsidian で別の Excalidraw ノートを画像として埋め込んだ図面では、埋め込み先のノートを読み込んで
SVG として表示する（入れ子にも対応）。その画像を右クリックすると
「webアプリで編集」（このアプリの新しいタブ）・「obsidianで表示」を選べる。詳細は [obsidian.md](obsidian.md)。

## 9. 共有ライブラリ

- 起動時に `public/excalidraw_lib/my_lib.excalidrawlib` を読み込む（アイテム・要素の ID は毎回振り直す。
  グループやテキストの所属先などの関係は保つ）
- ライブラリにアイテムを追加・削除すると自動で保存する。空にする変更と、読み込んだだけの通知では保存しない

## 10. PWA・オフライン

- ブラウザからアプリとしてインストールできる（`public/manifest.json`）
- 一度読み込んだアセットは Service Worker がキャッシュし、サーバーに届かないときも画面は表示できる。
  ファイルの読み書き・API はオンライン（サーバーに届くこと）が必要
