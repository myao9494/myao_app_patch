# キーボードショートカット一覧機能（. キー）仕様書

## 概要
ショートカットキー `.`（ピリオド）を押下した際、または上部ヘッダーのキーボードアイコンをクリックした際に、本アプリケーションで設定されているショートカットの一覧をモーダルダイアログで表示する機能です。
※ `H` キーはExcalidraw標準の手のひらツール（パン）と競合するため、本アプリのショートカットヘルプは `.`（ピリオド）に割り当てられています。

## 主な機能仕様

### 1. 起動と終了
- **起動トリガー**:
  - キーボードの `.`（ピリオド）キー単独押下
  - ヘッダー左側のアクションボタン「ショートカット一覧 (.)」クリック
- **無効条件**:
  - テキスト入力フィールド（`input`, `textarea`, `[contenteditable]`）にフォーカスがある場合
  - `Cmd` または `Ctrl` などの修飾キーが押されている場合（ブラウザやOSのショートカットと競合防止）
- **終了（クローズ）トリガー**:
  - 再度 `.` キーを押下（トグル動作）
  - `Esc` キー押下
  - モーダル外側の背景（オーバーレイ）をクリック
  - 右上の閉じるボタン（×）またはフッターの「閉じる」ボタンをクリック

### 2. モーダルUI構成
- **ヘッダー**: タイトル、`.` バッジ、閉じるボタン
- **ツールバー**:
  - **インクリメンタル検索バー**: キー名、説明、詳細のキーワードでリアルタイム絞り込み（クリアボタン付き）
  - **カテゴリ切り替えタブ**:
    - `すべて`: 全ショートカット
    - `独自機能`: アプリ固有の拡張ショートカット
    - `描画ツール`: Excalidraw基本ツール選択
    - `編集・操作`: 保存、取り消し、グループ化などの操作
- **ボディ**:
  - 各ショートカットカード（`<kbd>` スタイルのキー表記、独自機能バッジ、機能名、補足説明）
  - 該当なし時の空ステート表示
- **フッター**: 操作ヒントおよび閉じるボタン

## 登録ショートカット一覧

### 独自機能 (`custom`)
| キー | 機能概要 | 詳細 |
| :--- | :--- | :--- |
| `.` | ショートカット一覧ヘルプの表示 / 非表示 | 本ダイアログを開閉します。 |
| `M` | マーカー機能（ハイライト） | テキスト選択時: 下半分に蛍光マーカー生成・グループ化。未選択時: マーカー矩形描画ツール。 |
| `U` | アンダーライン機能（赤色下線） | テキスト選択時: 下端に赤色下線付与・グループ化。未選択時: 赤色直線描画ツール。 |
| `,` | マーカーとアンダーラインの設定パネル | 色・太さ・透明度の設定パネルを開閉します。 |
| `C` | 矢印なしの直線描画 | 矢印ヘッドのない直線描画ツールに切り替えます。 |
| `N` | 基本付箋（Sticky Note）の作成 | カーソル位置に黄色の四角い付箋メモを作成します。 |
| `W` | クリップボードからリンク付箋を作成 | クリップボード内のURL/テキストからリンク付き付箋を生成します。 |
| `Tab` | 選択図形の形状切り替え | 選択中の図形形状を四角形 → ひし形 → 円の順に変更します。 |
| `Cmd/Ctrl + S` | 手動保存（強制バックアップ） | サーバーへ即時保存し、バックアップを更新します。 |
| `Cmd/Ctrl + M` | 最前面に移動 | 選択中の要素を最前面へ移動します。 |
| `Cmd/Ctrl + B` | 最背面に移動 | 選択中の要素を最背面へ移動します。 |

### 描画ツール (`tools`)
| キー | 機能概要 |
| :--- | :--- |
| `V` / `1` | 選択ツール |
| `R` / `2` | 四角形ツール |
| `D` / `3` | ひし形ツール |
| `O` / `4` | 楕円・円ツール |
| `A` / `5` | 矢印ツール |
| `L` / `6` | 直線ツール |
| `P` / `7` | ドロー（フリーハンド） |
| `T` / `8` | テキストツール |
| `E` / `0` | 消しゴムツール |
| `H` | 手のひらツール（ハンド / パン） |

### 編集・操作 (`edit`)
| キー | 機能概要 |
| :--- | :--- |
| `Cmd/Ctrl + Z` | 元に戻す (Undo) |
| `Cmd/Ctrl + Shift + Z` | やり直し (Redo) |
| `Cmd/Ctrl + A` | 全選択 |
| `Cmd/Ctrl + C` / `Cmd/Ctrl + V` | コピー / 貼り付け |
| `Cmd/Ctrl + D` | 複製 (Duplicate) |
| `Delete` / `Backspace` | 要素の削除 |
| `Cmd/Ctrl + G` | グループ化 |
| `Cmd/Ctrl + Shift + G` | グループ解除 |
| `Space + ドラッグ` | パン（キャンバス移動） |
| `+` / `-` | 拡大 / 縮小 (Zoom) |
| `Esc` | 選択解除 / モーダルを閉じる |
