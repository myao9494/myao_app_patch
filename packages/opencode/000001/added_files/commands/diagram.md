スキル `excalidraw-diagram` を読み込み、その手順に従って、次の図を作ってください: $ARGUMENTS

種類(フロー図・スイムレーン・ツリー・マインドマップ)と保存先は、書かれていなければ、内容から決めて作り、決めたことを報告してください。図にする内容が分からないときだけ、作らずに質問してください。

読み込めなかったときは、読み込めなかったことを最初に報告してください。
