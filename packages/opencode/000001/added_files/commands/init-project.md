---
description: プロジェクトのフォルダを初期設定する。中身を見てテンプレートを選び、AGENTS.md を埋めて置く(使い方 /init-project フォルダ)
---

スキル `project-init` を読み込み、その手順に従って、次のフォルダを初期設定してください: $ARGUMENTS

フォルダが書かれていないときは、何も置かずに質問してください。中身があるときは、中身を読んでテンプレート(coding / 一般資料)を選び、中身から分かることで AGENTS.md の下書きを埋めて、分からないことだけを質問してください。`plan` の内容と下書きを私に見せて、承認を得るまで、`apply` は実行しないでください。`Git で管理されていません` と出たときは、承認の後に、スキルの手順どおり `git init` も実行してかまいません(リポジトリの途中のフォルダでは実行しない)。
