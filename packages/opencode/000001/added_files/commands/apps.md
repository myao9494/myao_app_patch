description: 自作の Web アプリを使う(使い方 /apps 依頼)。タスク、画像の差分、URL
---

スキル `app-ecosystem` を読み込み、その手順に従って、次の依頼を自作の Web アプリで行ってください: $ARGUMENTS

最初に `status` で、使うアプリが起動しているかを確かめてください。依頼が空なら、`status` の結果を見せて、何をしたいかを質問してください。タスクの作成・変更は、`--dry-run` の内容を私に見せてから、続けて実行してください(実行のときに確認のダイアログが出るので、文章で重ねて承認を求めなくてよい)。依頼に無い項目は変えないでください。

読み込めなかったときは、読み込めなかったことを最初に報告してください。
