# 動作確認と今日の日付

## 何をするか

今日の日付・曜日・時刻、AI_work の場所、Python と `.venv`、ハーネスのスキル(`browser-session`・`outlook-mail` など)の有無、自動化の数を表示する。読むだけで、何も変えない。自動化の見本も兼ねる(作りは `automation-builder` の `python` のひな形と同じ)。

## 入力

無し。`--json` を付けると JSON で出る。

## 手順

1. 実行する。

   ```
   <このスキルのフォルダ>\run.bat
   ```

2. 結果をそのまま示す。「なし」の項目があれば、次を添える。
   - `AGENTS.md` なし: AI_work に、テンプレートの `AGENTS.md` がコピーされていない
   - ハーネスのスキルなし: `%USERPROFILE%\.config\opencode\skills\` にハーネスが置かれていない
   - `.venv` なし: 標準ライブラリだけの自動化は動く。パッケージが要る自動化は、スキル `python-env` で作る
3. 「今日」「明日」「来週の月曜」を日付にするときは、ここの「今日」を基準にする。暗算せず、日付の計算はスクリプトで行う。

## 取り消せない操作

無し。

## 確かめたこと

| 日付 | 内容 | 結果 |
|---|---|---|
| 2026-11-12 | 自宅の Mac で `run.sh` とテスト | 動いた。会社の Windows・ランチャーからは未確認 |
