# 利用者のプロフィール

毎回読み込まれる。いつも前提にすること。2,000 文字以内。【 】を書き換え、要らない行は消す。
追記・削除は `/remember`(スキル `memory`)で行う。他人のことは書かない(人物ノート `people` へ)。

## 環境

- PC は Windows 11(64bit)。シェルは PowerShell。パスは `C:\Users\…` の形で、区切りは `\`。
- コマンドは PowerShell の書き方で示す(`ls -la`・`rm -rf`・`/tmp` のような Mac・Linux の書き方は使わない)。
- インターネットには直接つながらない。Python はプロジェクトごとの `.venv\Scripts\python` を使う。

## 立場

- 所属: 【部署】。役割: 【例: 〇〇の設計担当】。
- 担当: 【例: 〇〇の設計計算、△△の手順書】。
- 決められること・決められないこと: 【例: 仕様の変更は課長の承認が要る】。

## 書き方の好み

- 【例: 社内向けの文は、です・ます調。表を多めに】

## よく使う場所

- 【例: 案件のフォルダ `D:\projects\`】
