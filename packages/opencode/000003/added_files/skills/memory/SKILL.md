## 前提

- プロフィールは `~/.config/opencode/memory/profile.md`(Windows は `%USERPROFILE%\.config\opencode\memory\profile.md`)。設定の `instructions` で、すべてのセッションの最初に読み込まれる。
- 無いときは、雛形 `~/.config/opencode/templates/memory/profile.md` をコピーして作る案を示す(作るのは承認の後)。
- 中身は人が読んで直せる Markdown。節は「環境」「立場」「書き方の好み」「よく使う場所」。合う節が無いときだけ、節を足す。

## 守ること

- **書くのは、利用者が言ったことだけ。** 会話から推測したことを足さない。推測で候補を出すときは、そう明記する。
- **書くのは、毎回前提にしたい短い事実だけ。** 1 行 1 事実。言い切りで書く。その場かぎりの作業や、ファイルを見れば分かることは書かない。
- **書かない:** パスワード、API キー、トークン、私的な連絡先・住所、健康・家族など私生活のこと。**他人のこと**は人物ノート(スキル `people`)へ。言われても書かず、理由を伝える。
- **保存は、承認の後。** 先に、どの節に、どの行を足す・直す・消すかを示す。
- 同じ内容や食い違う行があれば、足さずに、古い行を直す案にする。
- **2,000 文字以内に保つ**(毎回読まれるため)。文字数は、Python の `len()` で測る(バイト数で測らない)。超えるときは、消す・まとめる案もあわせて示す。

## 覚える

1. プロフィールを読む。
2. 言われたことを、1 行 1 事実に書き直し、入れる節を決める。
3. 足す行(直す行・消す行があれば、その前後)を示し、承認を得る。
4. 承認の後に編集する。編集の後、文字数を測って報告する。
5. 「次のセッションから効きます(いまの会話には、すでに伝わっています)」と伝える。

## 忘れる

1. プロフィールから、当てはまる行を探して示す。
2. 承認の後に、その行を消す。消した行を報告する。
