# Spoonfeeder2 運用ルール

## 基本方針

- 最初に、変更対象となるメインリポジトリを1つ指定する。
- 作成した`repository_context.txt`をAIチャットへ添付し、依頼内容はチャット本文へ記載する。コンテキスト自体には依頼文を含めない。
- コンテキストには、選択したファイル本文とignored項目を除くリポジトリ構造を含める。トークン集計やコメント除外は行わない。
- Gitリポジトリでは`.gitignore`等のGit判定を優先する。Spoonfeeder2独自の無視設定は`.spoonfeeder.json`または既存の`.ignore_context`へ保存する。

## メインリポジトリと参照リポジトリ

- コード反映、テスト実行、ターミナルの作業ディレクトリはメインリポジトリだけとする。
- 通常Pythonモードでは、選択中のPython/C#コードが利用する外部ソースをvenv、環境変数、`sys.path`、`ProjectReference`、`.sln`から自動検出する。
- 外部リポジトリは読み取り専用の参照ライブラリとして扱い、利用中の`.py`／`.cs`だけをコンテキストへ追加できる。文書ファイルは参照側へ含めない。
- 自動解決できない参照だけ、右クリックの「対象リポジトリを追加」で手動対応付けする。
- Embedded Pythonモードでは、外部参照リポジトリ機能を使用しない。

## AI変更の反映

AIチャットへ渡す`repository_context.txt`には、一般利用者向けに調整された会社チャットでも出力が揺れないよう、次の回答契約を毎回含める。長いリポジトリ本文の後でもルールを見失いにくいよう、コンテキスト先頭に詳細契約、末尾に短い再確認を配置する。

| 形式 | 用途 | 出力方法 |
| --- | --- | --- |
| 形式1（最優先） | 関数・メソッドの変更 | ファイルパス付きコードブロックで、変更後の関数／メソッド定義全体を出力する |
| 形式2 | グローバル変数など関数化されていないコード | ファイルパス付きコードブロックで出力し、置換位置を変数名等の検索キーワードで示す |
| 形式3 | 複数ファイル、新規・削除、全文置換 | `<file_changes>`の各`<file>`へpath、action、変更後ファイル全文を出力する |

- 関数変更では形式1を積極的に使用し、同一ファイルの複数関数は1つのコードブロックへまとめる。
- 全形式でリポジトリ相対のファイルパスを必ず明示し、変更不要なファイルは出力しない。
- `<change_manifest format="yaml">`はYAMLとして出力し、ファイルの箇条書きには必ず`- path:`を使用する。
- 変更箇所は行番号ではなく、関数名・クラス名・変数名などの検索キーワードで案内する。
- テストはモックを使わない統合テストとし、`pytest/{モジュール名}_test.py`へ配置する。1テスト1確認、日本語のテスト名、環境依存箇所の`pytest.mark.skipif`を必須とする。

1. AI回答を「AIの変更を反映」へ貼り付ける。
2. 「差分を確認」で対象ファイルと変更内容を確認する。
3. AIへの出力指示ではファイルパスを必須とする。Spoonfeederは回答が不完全な場合に限り、一意な関数／メソッド名から反映先を補完する。
4. 差分が妥当な場合だけ反映し、続けて対象リポジトリのテストを実行する。
5. テスト失敗時は出力をAIへ戻して修正する。途中の書き込み失敗時は変更前へ自動復元されるが、通常の版管理と最終確認にはGitを使用する。

参照リポジトリを変更先として指定しない。既存ファイルの文字コード、BOM、改行コードは原則として維持されるが、反映前の差分確認は省略しない。

## 起動と配布

- macOS/Linuxは`./start.sh`、Windowsは`start.bat`で起動する。既定ポートは8077、既定の待受アドレスは`127.0.0.1`（このPCのブラウザからのみ接続できる）で、起動時に同じポートの既存プロセスを終了する。
- 他のPCからアクセスさせる場合だけ`SPOONFEEDER_HOST`でアドレスを指定する。認証はなく、テスト実行・ターミナル・ファイル書き換えが可能になるため、信頼できるネットワークに限る。詳細は README の「セキュリティ」を参照する。
- 配布物には`frontend/dist`を含める。これにより、運用PCではNode.jsを不要にできる。
- WindowsではPython 3.10以上と`backend\requirements.txt`の依存関係を導入する。`pywinpty`はWindowsでのみ導入され、ブラウザ内ターミナルに使用される。
- 日本語パスを利用できる。ソースはUTF-8、UTF-16、CP932を読み込めるが、新規ファイルと設定ファイルはUTF-8で作成する。

## 日常操作

- ファイル選択ツリーをクリックしてフォーカスし、`↑`／`↓`で項目を移動する。ファイル上の`Enter`はチェックのオン／オフ、`Shift+Enter`は中身の表示、フォルダ上の`Enter`・`←`・`→`は開閉に使用する。
- `I`: 無視リスト編集
- `H`: ショートカットと設定の説明
- 無視リスト編集中の`Ctrl/Cmd+S`: 保存して閉じる
- `Esc`: 保存せず閉じる（ファイルプレビューも閉じる）
- `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z`: 無視リスト編集のUndo／Redo
- ファイルプレビュー検索の`Enter`、`Shift+Enter`: 次／前の一致へ移動
