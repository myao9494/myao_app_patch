# 類似語・専門用語の一元管理仕様

## 概要
本アプリケーションでは、検索クエリに含まれる単語に対する同義語展開（通常キーワード検索）と、セマンティック検索・AIインプットで活用される専門用語辞書（意味検索）の2つの用途を、**単一の設定ファイル（`synonym_groups.txt`）で一元管理**しています。

ユーザーはWeb UIの「検索ルール管理 > 類似語・専門用語リスト」から編集・保存を行うだけで、通常検索エンジンとベクトル意味検索エンジンの両方に自動即時反映されます。

---

## 設定形式 (`synonym_groups.txt`)

1行に「カンマ区切りの類似語」と、コロン（`:` または `：`）に続く「意味・解説文（任意）」を記述します。

### 書式
```text
用語1, 用語2, 用語3, ... [: 意味・解説文]
```

- **類似語部分（コロンより前）**: カンマ（`,`）または全角カンマ（`，`）で区切られた同意語・表記揺れのリスト。
- **意味・解説文（コロンより後、任意）**: 用語の意味、定義、使われ方などの説明文。
- **重複排除**: 同一グループ内では大文字小文字違いを含めて重複を自動排除します。
- **後方互換性**: コロンおよび解説文を記述しない行は、従来の同義語リストと完全に同じものとして扱われます。

### 記述例
```text
PC, パソコン, パーソナルコンピュータ : 個人向けコンピュータ端末全般
iPhone, アイフォン, アイフォーン : Apple製のスマートフォンシリーズ
Google, グーグル : 検索エンジンおよびITサービス企業
RAG, 検索拡張生成 : 外部文書を検索してLLMへの入力コンテキストを補強する手法
AI, 人工知能
```

## 検索エンジンごとの動作と役割分担

| 検索タイプ | 使用する部分 | 動作・目的 |
| :--- | :--- | :--- |
| **通常検索**<br>(キーワード検索 / FTS5) | **コロンより前**の類似語のみ | クエリ中の用語を類似語で OR 展開して見落としを防止。<br>※解説文はキーワード展開に**混入させない**ため、余計なノイズによる誤ヒットが発生しません。 |
| **意味検索**<br>(ハイブリッド / ベクトル / AIインプット) | **類似語 ＋ 意味・解説文**の両方 | `GlossaryDictionary` としてロード。<br>最長一致で用語を検知し、表記揺れ展開および意味的コンテキストの補強としてベクトル検索・AIプロンプト生成に活用されます。 |

## API 仕様

### 1. 同義語・専門用語取得API
設定されたリストを構造化データとして取得します。

- **メソッド**: `GET`
- **パス**: `/api/index/synonyms`
- **レスポンス形式**:
```json
{
  "groups": [
    ["PC", "パソコン", "パーソナルコンピュータ"],
    ["iPhone", "アイフォン", "アイフォーン"],
    ["Google", "グーグル"],
    ["RAG", "検索拡張生成"],
    ["AI", "人工知能"]
  ],
  "entries": [
    {
      "terms": ["PC", "パソコン", "パーソナルコンピュータ"],
      "description": "個人向けコンピュータ端末全般"
    },
    {
      "terms": ["iPhone", "アイフォン", "アイフォーン"],
      "description": "Apple製のスマートフォンシリーズ"
    },
    {
      "terms": ["Google", "グーグル"],
      "description": "検索エンジンおよびITサービス企業"
    },
    {
      "terms": ["RAG", "検索拡張生成"],
      "description": "外部文書を検索してLLMへの入力コンテキストを補強する手法"
    },
    {
      "terms": ["AI", "人工知能"],
      "description": ""
    }
  ]
}
```
- `groups`: 通常検索用の同義語展開リスト（解説を除外したもの）。
- `entries`: UI表示および専門用語辞書用の構造化リスト（類似語リストと解説文）。

### 2. 設定保存・ホットリロード
- **メソッド**: `PUT`
- **パス**: `/api/index/settings`
- **処理の流れ**:
  1. `synonym_groups` を正規化して `backend/data/synonym_groups.txt` に保存。
  2. `IndexService` 内の同義語インメモリキャッシュを即時更新。
  3. 連動して `vector_state.reload_glossary()` を自動実行し、ベクトル意味検索用の辞書キャッシュを即時ホットリロード。
  4. サーバー再起動なしで、通常検索と意味検索の両方に最新の辞書が適用されます。

## Web UI

- **設置場所**: 「検索ルール管理」画面の「類似語・専門用語リスト」カード。
- **表示機能**:
  - 各行に類似語のバッジ一覧と、解説がある場合は吹き出しアイコン（💬 `解説内容`）を表示。
  - 検索欄により、類似語または解説文の部分一致で高速フィルタリングが可能。
  - ダブルクリックにより行単位でのインライン編集が可能。
- **追加モーダル**:
  - 「類似語（必須）」入力欄と「意味・解説（任意）」入力欄の2段UIを提供。
  - 既存の類似語や除外キーワードとの重複・競合を自動チェック。
