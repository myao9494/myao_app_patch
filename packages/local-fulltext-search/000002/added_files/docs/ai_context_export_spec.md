# AI インプット (Chat AI Export) 仕様書

## 1. 概要
本機能は、ハイブリッド検索やベクトル検索の結果から、ユーザーが必要なファイルを選択し、ChatGPT や Claude 等の AI チャットにそのまま入力（コピペまたはファイルアップロード）できる**完全自己完結型 HTML ファイル**を生成する機能である。
外部リソースへの依存を排除し、画像や Excalidraw / draw.io 図面を Base64 インライン化することで、AI が視覚情報（図表・フローチャート・画面構成）も含めて完全にドキュメントを理解できるように設計されている。

## 2. 主な機能と構成

### 2.1 ドキュメント選択 & 抽出 (PoC 準拠リッチ UI)
- **ドラッグ範囲選択**: マウスドラッグで矩形/複数行の直感的な連続選択が可能。
- **Shift + ドラッグ解除**: Shift キーを押しながらドラッグすることで選択を直感的に解除。
- **検索結果連動 & パス直接追加**: 検索画面の上位結果だけでなく、手動でのファイルパス指定追加にも対応。
- **全選択 / 全解除**: 1クリックで候補を一括選択・全解除。
- **自動タイトル推定**: 選択されたドキュメントの共通パスやファイル名からエクスポートタイトルを賢く自動提案。
- **リアルタイムトークン数概算**: 選択ファイル群の合計文字数から AI の消費トークン（推定値）をリアルタイムに計算・警告表示。
- **除外キーワードの厳格適用**: 除外キーワードはファイル名に対する除外フィルタとして機能し、ファイル名（またはパス）に除外キーワードが含まれるファイル（例: `gantt_diff_summary.json` や `2026_gantt_diff_summary_v1.md` 等）を候補一覧や検索結果から自動的・確実に除外。


### 2.2 プロンプト設定
- **プリセットテンプレート（5種網羅）**:
  - `統合サマリー`: 提供された複数ドキュメントを統合した要約と論点整理を指示。
  - `課題・ToDo抽出`: ドキュメントから未解決の課題、アクションアイテム、ToDo を抽出。
  - `Q&A・質問応答`: 添付資料に基づき、前提知識なしでも正確に回答することを指示。
  - `コード設計・実装計画`: 仕様書に基づくシステム設計、データ構造、実装タスク分解を指示。
  - `差分・変更点分析`: 複数ドキュメント間やバージョン間の変更点・相違点を分析。
  - `カスタム`: ユーザー独自のプロンプトを自由に入力可能。

### 2.3 自己完結型 HTML 生成エンジンの仕様
1. **画像・図面インライン化 (Base64 Data URI)**:
   - Markdown やテキスト内の画像リンク（`![alt](path)`）を検出し、ローカルの画像実体（PNG, JPG, GIF, SVG 等）を Base64 Data URI に変換して `<img>` タグへ置換。
   - `.excalidraw` / `.excalidraw.md`: 描画シーンの SVG データを生成または埋め込み画像から復元し、SVG/Base64 として埋め込み。
   - `.dio` / `.dio.svg`: draw.io の XML/SVG データをそのまま SVG としてインライン展開。
2. **構造化ドキュメント**:
   - 先頭に AI 向けの `<system-instruction>` / プロンプトブロック。
   - 目次（Table of Contents）リンク一覧。
   - 各ドキュメントごとにメタ情報（ファイル名、パス、更新日、ファイルサイズ）を明記。
   - HTML レンダリング表示と、AI が直接テキスト解析できる `<details>` 内の Raw Markdown の両方を保持。
3. **スタイル & デザイン**:
   - Glassmorphism & モダンデザイン（CSS がすべて `<style>` にインラインで同梱）。
   - オフラインでも完全に閲覧可能（CDN や外部フォント、外部スクリプトを一切ロードしない）。

### 2.4 出力とデュアルタブ表示
- **デュアルタブ切替**:
  - `プレビュー`: 画面内のサンドボックス化された `<iframe>` で生成結果をリアルタイムプレビュー。
  - `HTML ソース`: 生成された生の自己完結 HTML コードを表示し、部分コピーや確認が容易。
- **HTML ダウンロード**: `.html` ファイルとしてローカルに保存（AI チャットへの添付ファイルアップロード用）。
- **クリップボードコピー**: HTML ソースをクリップボードにワンクリックコピー（プロンプト欄への直接貼り付け用）。
