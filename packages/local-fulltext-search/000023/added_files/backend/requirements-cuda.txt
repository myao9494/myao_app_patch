# ==============================================================================
# Windows NVIDIA GPU (RTX A500 等) 専用 requirements
#
# 使用方法（通常は setup_windows_cuda.bat が実行する）:
#   .venv\Scripts\python.exe -m pip install -r requirements-cuda.txt
#
# PyTorch 公式の CUDA 12.6 の索引を足して、requirements-lock.txt と同じ版を入れる。
# torch だけは GPU 版の 2.14.1+cu126 を明示する（requirements-lock.txt の torch==2.14.1 も満たす）。
# 明示しないと、CPU 版の 2.14.1 が入った venv では「入っている」と見なされ GPU 版に入れ替わらない。
# CUDA 12.4 の索引には Python 3.14 用の torch が無く、黙って CPU 版が入ってしまうため使わない。
# ==============================================================================

--extra-index-url https://download.pytorch.org/whl/cu126
torch==2.14.1+cu126
-r requirements-lock.txt
