# インデックス済みフォルダ管理ページ

## 目的
- 実際にインデックス済みファイルを含むすべてのフォルダを一覧で確認する
- 実際にインデックス済みWebページをURL単位で一覧確認し、必要なページを選択する
- キーワードで対象を絞り込み、複数選択してインデックスを削除する
- 検索対象フォルダ（インデックス作成の許可対象）を有効/無効で管理する

## 画面仕様
- 画面上部のタブから `インデックス済みフォルダ` / `インデックス済みWebページ` / `検索対象フォルダ` ページへ切り替える
- 一覧には以下を表示する
  - フルパス
  - インデックス済みファイル数
  - 最終インデックス日時
- 一覧は `targets` の管理レコードではなく、`files` テーブルから祖先フォルダを展開して構成する
- `インデックス済みWebページ` は `files.source_type='web'` の `normalized_path` をURLとして1ページ1カードで表示する
- `インデックス済みWebページ` のカードにはURLを表示し、`Webページを開く` でブラウザの新規タブを開く
- `キーワードで絞り込み` はフルパスを対象に部分一致で絞り込む
- `すべて選択` は現在の絞り込み結果に含まれる行だけを対象にする
- `選択したフォルダのインデックスを削除` は確認ダイアログ後に実行する
- `インデックス済みWebページ` では、絞り込みキーワードをWeb専用の除外キーワードへ追加できる
- `検索対象フォルダ` タブでは、各行のチェックボックスで有効/無効を切り替えられる
- `検索対象フォルダ` タブでは、行単位で `削除`、`インデックス削除`、`インデックス再取得` を実行できる
- `インデックス取得` は現在の絞り込みに一致する有効な検索対象フォルダをまとめてインデックスする
- 起動URLの `full_path` が検索対象フォルダに含まれない場合、検索画面に `検索対象に追加` ボタンを表示する
- `検索対象に追加` は、検索欄の階層数で登録する。階層の欄が空のときは、欄の表示どおり無制限として登録する
- 既に親フォルダが検索対象なら、子フォルダは追加候補として扱わない

### 見つからない検索対象フォルダ
- 移動・削除・未接続のドライブ・権限不足でフォルダが見つからない検索対象は、インデックスを更新できない（変更追跡も見送る）
- `インデックス済みフォルダ` タブでは、見つからない検索対象の配下にある行に × を付けて赤く表示し、「フォルダが見つかりません」と書く
  - 判定は登録した検索対象の単位で行う。フォルダごとに存在を確かめると、未接続のネットワークドライブで一覧が遅くなるため
- `検索対象フォルダ` タブでも、フォルダが見つからない行に同じ表示をする
- インデックスは自動では消さない。利用者が行を選んで `選択したフォルダのインデックスを削除`（検索対象の登録は `検索対象フォルダ` タブの `削除`）で消す
- 未確認の見つからないフォルダがあれば、起動時とインデックスの完了後に、どのページでもポップアップで案内する
  - 「確認しました」で確認済みにし、同じフォルダは再び案内しない。フォルダが見つかるようになったら確認済みを解除し、また見つからなくなったら案内する
  - たどらなかったリンクの案内が開いているあいだは重ねず、閉じてから開く

## API 仕様
- `GET /api/index/targets`
  - `source_type=local` の場合、`files` から展開したインデックス済みフォルダ一覧を返す。見つからない検索対象の配下の行は `is_missing=true`
  - `source_type=web` の場合、インデックス済みWebページ一覧をURL単位で返す
- `DELETE /api/index/targets`
  - `target_paths` に含まれるフォルダ配下またはWeb URLのインデックスを削除する
  - 対象フォルダ配下の `files` / `file_segments` / `failed_files` も削除する
  - 重なる `targets` は `last_indexed_at = NULL` と `indexed_file_count = 0` に戻し、次回検索で再インデックスさせる
- `GET /api/index/search-targets`
  - 検索対象フォルダ一覧（`is_enabled` と、ローカルのフォルダが見つからないことを示す `is_missing` を含む）を返す
- `GET /api/index/missing-targets`
  - フォルダが見つからない有効なローカル検索対象のうち、未確認のものを `items[].full_path` で返す
  - フォルダが見つかるようになった対象の確認済みは、ここで解除する
- `POST /api/index/missing-targets/acknowledge`
  - `full_paths` の検索対象を確認済みにし、新しく確認済みになった件数を `acknowledged_count` で返す
- `PUT /api/index/search-targets`
  - `folder_path` 単位で検索対象の有効/無効を更新する
- `POST /api/index/search-targets`
  - 検索対象フォルダへ新規追加し、有効状態にする
- `POST /api/index/search-targets/reindex`
  - 指定した検索対象フォルダ群を順次再インデックスする
- `DELETE /api/index/search-targets`
  - 指定した検索対象フォルダを一覧から削除する
