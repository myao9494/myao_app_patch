# Excalidraw Data

## Text Elements
画像右下ドラッグ拡大縮小（リサイズハンドル）操作フロー ^title
① 画像コンテナの右下にハンドルを自動配置 ^step1-title
画像ホバー時または選択時にアクセントカラーのハンドル（nwse-resize）が出現 ^step1-desc
② マウスドラッグで直感的に拡大・縮小 ^step2-title
ハンドルを掴んでドラッグ！現在のサイズをHUDツールチップ（例: 350px）でリアルタイム表示 ^step2-desc
③ ドラッグ完了時にノート本文を自動更新 ^step3-title
![[image.png|350]] のようにMarkdownリンクを自動更新・保存し、サイズを永続化 ^step3-desc
④ ダブルクリックで元のサイズにリセット ^step4-title
ハンドルをダブルクリックすると |350 を削除し、画像本来のサイズに瞬時に復元 ^step4-desc
