## Text Elements
ファイルマネージャー連携（DnDリンク生成 ＆ 同一フォルダ保存） ^title
① Webアプリからドラッグ＆ドロップ ^step1-title
JSONデータを解析し localhost:8001 の open-path リンクを即座に挿入 ^step1-desc
[aaa.md](http://localhost:8001/api/open-path?path=/Users/...) ^step1-link
② 右クリックメニューの追加 ^step2-title
エディタ（editor-menu）＆ 閲覧モード（contextmenu）の両方に対応 ^step2-desc
「コピーして同一フォルダーに保存」 ^step2-menu
③ 同一フォルダへのコピー ＆ Obsidianリンク変換 ^step3-title
1. 元ファイルの存在確認（なければNotice通知） ^step3-p1
2. 同階層に同名ファイルがあれば上書き確認ダイアログ ^step3-p2
3. fs.copyFileSync でノートと同じフォルダーへ安全コピー（関連画像・添付ファイルも一括コピー！） ^step3-p3
4. 画像は ![[xxx.png]]、他は [[xxx.md]] に自動置換！ ^step3-p4
