## Text Elements
マークダウン編集時 右クリックメニュー拡張アーキテクチャ ^title
① エディタ右クリック (editor-menu) ^box-trigger-title
編集画面上で右クリック。タブまでカーソルを移動する手間を解消！ ^box-trigger-desc
② メニュー項目（最上部に自動並び替え） ^box-menu-title
1. 📁 フォルダを開く (親ディレクトリをFinder/Explorerで開く) ^box-menu-item1
2. 🚀 VS Codeで開く (対象ファイルをVS Codeで外部編集) ^box-menu-item2
③ フォルダを開く処理フロー (openContainingFolder) ^box-folder-title
1. Electron shell.openPath(folderFullPath) ^box-folder-step1
2. OSコマンド (Mac: open / Win: explorer / Linux: xdg-open) ^box-folder-step2
3. Obsidian標準 app.showInFolder(file.path) ^box-folder-step3
④ VS Code起動処理フロー (openInVsCode) ^box-vscode-title
1. 設定パス (Sidebar Explorer vscodeExecutablePath) ^box-vscode-step1
2. OS別コマンド (open -a "Visual Studio Code" / Code.exe / code) ^box-vscode-step2
3. URLスキーム (vscode://file/<path>) ^box-vscode-step3
