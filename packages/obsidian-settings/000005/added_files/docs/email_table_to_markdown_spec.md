# メール本文（HTML/RTF）表（テーブル）Markdown変換 仕様書

## 1. 背景と課題

### 課題
Outlookのメール（`.msg`、`winmail.dat` 等）を「サマリーを作る」で取り込む際、メール本文に含まれるスケジュール表や一覧表などの「表（テーブル）」が、Markdownの表として出力されず、セル内の文字列が単に改行された平坦なテキストになり、表構造が崩壊してしまう問題が発生していました。

### 原因
1. **HTMLサニタイズ時のテーブルタグ破壊**:
   - `renderMsgBodyWithImages` および `htmlToPlainText` において、`<\/(table|tr|td|th)\s*>` が改行置換や一括消去対象となっていたため、セルがバラバラの行に分割されていた。
2. **プレーンテキスト本文の誤った優先**:
   - 画像添付のないメールの場合、Outlookが平坦化したプレーンテキスト（`parsed.Body`）を最優先していたため、HTML内にテーブル構造が存在していてもHTML全体が無視されていた。
3. **RTFテーブル制御語の未処理**:
   - 純粋なRTFメール内の表制御語（`\trowd`, `\cell`, `\row`）が無視され、セル文字列がそのまま結合されていた。

## 2. 処理フロー

```
[メール本文 (HTML / RTF / TNEF)]
           │
           ├── HTMLテーブル検知 (<table\b)
           │
           ├─ [検知あり] ──> 画像の有無に関わらず HTML 処理を優先
           │                 │
           │                 ▼
           │        【convertHtmlTablesToMarkdown】
           │        ・<tr>, <th>, <td> を解析
           │        ・セル内の改行/不要タグを除去、パイプをエスケープ
           │        ・ヘッダー行、区切り線 (| --- |)、データ行を生成
           │        ・Markdownテーブル (| 列1 | 列2 |) に置換
           │
           ├─ [純粋RTF] ───> 【extractPlainTextFromRtf】
           │                 ・\cell, \row 制御語を追跡
           │                 ・テーブル行を蓄積して Markdownテーブルへ変換
           │
           ▼
[サマリー APPENDIX へ出力]
・ヘッダーや枠線が綺麗に揃ったMarkdownテーブルとして展開！
```

## 3. 機能仕様詳細

### 3.1 HTMLテーブルのMarkdown変換 (`convertHtmlTablesToMarkdown`)
- **対象**: `<table\b[^>]*>([\s\S]*?)<\/table>`
- **セル抽出と整形**:
  - 行単位（`<tr>`）でスキャンし、各セル（`<th>` / `<td>`）の内容を抽出。
  - セル内の `<br>` はスペースに置換（またはインライン化）。
  - セル内のタグ（`<p>`, `<span>`, `<b>` 等）およびHTMLエンティティ（`&nbsp;`, `&lt;` 等）をテキスト化。
  - セル内のパイプ文字 `|` を `\|` にエスケープ。
- **ヘッダーおよび区切り線の自動生成**:
  - 最大列数 `maxCols` を算出し、不足するセルを空文字でパディング。
  - 1行目をヘッダー行 `| 列1 | 列2 | ... |`、2行目を区切り線 `| --- | --- | ... |`、3行目以降をデータ行として構成。
  - 前後に空行を確保して Markdown テーブルを出力。

### 3.2 HTML優先判定の最適化
- メール内に埋め込み画像がない場合でも、`/<table\b/i.test(html)` が真であれば、表構造のないプレーンテキスト（`parsed.Body`）を破棄し、テーブル変換を適用したHTML本文を採用。

### 3.3 RTFテーブルのサポート (`extractPlainTextFromRtf`)
- `\cell` / `\nestcell`: セルテキストを確定。
- `\row` / `\nestrow`: 行を確定し、テーブル行リストに格納。
- 通常テキストや段落制御語（`\par`）への切り替わり、またはドキュメント末尾で、蓄積したテーブル行を Markdown テーブル文字列へフラッシュ。
