# Excalidraw Data

## Text Elements
Before (変更前: 幅100%引き伸ばし) ^t-before-title

min-width: 100% により横幅いっぱいに引き伸ばされ、
セルの罫線が不要に長くなってしまう ^t-before-desc

| 項目 | 内容                      | 備考     |
| A    | これはAの内容です         | 問題なし | ^t-before-tbl

After (変更後: コンテンツ幅に最適化) ^t-after-title

CSSで min-width: unset に上書き。
通常の表と同様にセルの長さに合わせて自然にフィット！ ^t-after-desc

| 項目 | 内容             | 備考     |
| A    | これはAの内容です | 問題なし | ^t-after-tbl

【編集ワークフロー】Shift + Tab で公式GUIを活用 ^t-workflow-title

1. 表全体を選択 ^t-step1

2. Shift + Tab ^t-step2

インデント解除
→ 公式GUI（+列追加）起動 ^t-step2-sub

3. GUIで列/行編集 ^t-step3

4. Tab ^t-step4

再インデント
→ 整然とした表へ戻る ^t-step4-sub
