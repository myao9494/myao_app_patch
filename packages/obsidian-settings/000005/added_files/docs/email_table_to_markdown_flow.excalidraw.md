# Excalidraw Data

## Text Elements
メール本文テーブルのMarkdown変換フロー ^title
① メール本文のテーブル検知 ^step1-title
HTML内の <table ...> または RTF内の \cell, \row を検出 ^step1-desc
② テーブル存在時の優先分岐 ^step2-title
画像なしでも表があれば平坦なプレーンテキストを回避し、
HTMLテーブル変換ルートを最優先！ ^step2-desc
③ テーブル構文の解析とMarkdown化 ^step3-title
【convertHtmlTablesToMarkdown】
・<tr>, <th>, <td> からセルデータを抽出
・セル内の改行/不要タグを除去、パイプ「|」をエスケープ
・ヘッダー行、区切り線（| --- |）、データ行を自動生成 ^step3-desc
④ サマリー（APPENDIX）への展開 ^step4-title
崩れのない美しいMarkdownテーブルとして展開！ ^step4-desc
