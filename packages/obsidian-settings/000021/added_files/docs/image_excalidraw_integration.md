# 仕様書: Excalidrawと画像のカードビュー統合（画像一覧の表示）

## 概要
使い勝手の悪かった従来の画像用 `.base` ファイル（`common_image_cards.base`、`data_cards.base`）を廃止し、自作プラグイン `obsidian-excalidraw-cards` 内にExcalidrawと画像を統合した「画像一覧の表示」ビューとしてマージします。

## 仕様詳細

### 1. 起動とUI統合
- **Sidebar Explorer最上部ボタンの統合**:
  - 最上部のアクションボタンは **「🖼️ 画像一覧の表示」** ボタン1つのみとします。
  - ボタンをクリックすると、統合ビューの開閉トグルコマンド（`obsidian-excalidraw-cards:excalidraw_open_close`）がトリガーされます。
- **リボンアイコンおよびスラッシュコマンドの登録**:
  - `obsidian-excalidraw-cards` プラグインは、リボンアイコン（ツールチップ: 「画像一覧の表示」）およびコマンド名「画像一覧の表示」（ID: `excalidraw_open_close`）を登録します。
  - スラッシュコマンド（コマンドパレット）からも「画像一覧の表示」を入力して起動可能です。

### 2. 統合ビュー内のタブ切り替え
ビュー上部に「すべて」「Excalidraw」「共有画像」「画像」「dio」「紐づきのない画像」の6つのタブ（切り替え用ボタン）を設け、選択されたタブに応じて `01_data` 配下のファイルを即座に切り替えて表示します。

| タブ名 | 表示対象ファイル | 絞り込み条件 |
| :--- | :--- | :--- |
| **すべて** | `01_data` 配下のすべての画像ファイル、Excalidraw ファイルおよび dio 関連ファイル | `01_data` 配下の `png/jpg/jpeg/gif/bmp/svg/webp`、`.excalidraw.md`, `_excalidraw.md` および `.dio`, `.dio.svg`, `.drawio`, `.drawio.svg` |
| **Excalidraw** | `01_data` 配下の Excalidraw ファイルのみ | `01_data` 配下の `.excalidraw.md`, `_excalidraw.md` |
| **共有画像** | `01_data/common_image` 配下の画像および Excalidraw ファイル | `01_data/common_image` 配下の `png/jpg/jpeg/gif/bmp/svg/webp` および `.excalidraw.md`, `_excalidraw.md` |
| **画像** | `01_data` 配下の画像ファイルのみ（Excalidraw、dio関連は除外） | `01_data` 配下の `png/jpg/jpeg/gif/bmp/svg/webp`（`.excalidraw.md`, `_excalidraw.md` および dio関連ファイル除外） |
| **dio** | `01_data` 配下の dio 関連ファイルのみ | `01_data` 配下の `.dio`, `.dio.svg`, `.drawio`, `.drawio.svg` |
| **紐づきのない画像** | `01_data` 配下で他ファイルから参照されていない画像、Excalidraw および dio 関連ファイル（共通画像フォルダ配下を除く） | `01_data` 配下の画像、Excalidraw および dio 関連ファイルのうち、他ファイルからのリンク（Wikilinkや埋め込み等）がなく（バックリンク数が0）、かつ共通画像フォルダ（`01_data/common_image`）配下以外のファイル |

### 3. カードのレンダリングおよびプレビューの最適化
- **Excalidrawファイル**:
  - 既存のプレビューキャッシュ生成機能（`.excalidraw-cache/` 配下にPNGプレビュー画像と `index.json` を非同期キャッシュする仕組み）を活用し、高精細な描画を行います。
  - キャッシュ済みファイルは即座に `<img>` として表示します。
  - キャッシュ未作成ファイルは、一覧表示時に全件一括生成せず、`IntersectionObserver` でカードが画面付近に入ったタイミングで生成します。これにより、画像一覧ビューを開いた状態でも通常のノート編集への影響を抑えます。
  - 検索・タブ切り替え・ファイル更新で再描画された場合、古い非同期生成結果が新しい画面へ書き戻らないよう、描画リビジョンを管理します。
- **画像ファイル**:
  - 追加 of キャッシュ作成などのオーバーヘッドを避けるため、キャッシュ生成プロセスを通さず、直接Obsidianの推奨API `app.vault.getResourcePath(file)` から `<img>` 要素としてプレビューを表示します。これにより表示速度を大幅に向上させます。
  - Windows環境におけるパス区切り文字（`\`）の影響を排除し、画像やファイルが正しく検出・フィルタリングされるよう、ファイルパスに対するプレフィックスチェックを行う際は、事前にパスの区切り文字を `/` に正規化（`replace(/\\/g, "/")`）した上で判定を行います。
- **タイトル表示**:
  - カード下部に表示されるタイトル名は、拡張子（`.excalidraw.md`、`_excalidraw.md`、または各画像拡張子）を除去して表示します。

### 4. 操作性（ドラッグ＆ドロップおよびクリック）
- 各カードは、ドラッグ＆ドロップにより編集中のマークダウンファイル内に埋め込み形式で貼り付けることができます。
  - **Excalidraw**: Webアプリ（http://localhost:3001/?filepath=... ）へのリンクと埋め込みテキスト（`![[ファイル名|1475]]`）の両方を挿入します。
  - **画像**: 単純な埋め込みテキスト（`![[ファイル名.拡張子]]`）のみを挿入します（Webアプリへのリンクや幅指定は含めません）。
- カードをクリックすると、メインエディタで対象ファイルを開くことができます（画像ファイルもタブで直接開きます）。画像一覧自身のタブは置き換えず、別のペインで開きます。別のペインが無ければ分割して開きます（`chooseCardOpenLeaf`）。

### 5. 自動更新（ファイル変更検知）
- Vault内でのファイル作成（`create`）、削除（`delete`）、リネーム（`rename`）イベントを監視します。
- 変更が検知されると、短いデバウンス後にファイルリストを再取得してビューを再レンダリング（`refreshView`）します。これにより、連続したファイル変更や同期直後でも再描画が過剰に走らないようにします。

### 6. ファイル重複表示の排除
- ファイルリストの取得時、同一ファイルパス（`path`）を持つ画像やExcalidrawが重複して一覧に表示されるのを防ぐため、パスに基づいた重複排除（`deduplicateFilesByPath`）を適用します。同じパスを持つ要素が存在する場合は、元のソート順（更新日時の降順）に従い、最初に出現した要素（最新の更新日時を持つもの）が優先されます。
