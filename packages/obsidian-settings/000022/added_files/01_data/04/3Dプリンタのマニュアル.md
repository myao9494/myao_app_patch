# 3Dプリンタ（slab S3DP555）造形マニュアル（PrusaSlicer + Printrun・Windows・初心者向け）

> [!info] このマニュアルについて
> - 対象: 3Dプリンタを初めて使う人。高校生でも、上から順に読めば造形まで進めるように書いている。OS は Windows。
> - 対象機種: 社内の **slab（エス・ラボ）S3DP555**。Prusa 純正機ではないため、PrusaSlicer では「他社製機（カスタムプリンタ）」として扱う。
> - 使うソフト:
>   - **PrusaSlicer**（スライサー）: 3D モデルから、プリンタへの動作命令（G-code）を作る。
>   - **Printrun（Pronterface）**: PC と USB ケーブルでつないだプリンタへ G-code を送って印刷する。**SD カードは使わない**。
> - 対象バージョン: PrusaSlicer **2.9 系**（2026-11-02 時点の安定版は 2.9.7。3.0 は試験版のため対象外）。Printrun は 2.2.0。
> - 画像は Prusa 公式ドキュメント（help.prusa3d.com）と Printrun 公式（GitHub）から保存したもの。画像の著作権はそれぞれに帰属するため、社内・個人利用に留めること。出典は 13 章。
> - S3DP555 の値・手順は、同じ機種を使っている京都大学の操作マニュアル（13 章）を参考にした。社内の機体と違う所があれば直すこと。
> - `【要確認】` は実機で確かめて書き換える項目、`【ユーザー記入】` は共有フォルダのパスや COM ポートなど、使う人が書き込む項目。

> [!danger] 必ず守ること（詳しくは 10 章）
> 1. **1層目は必ず最後まで見てから席を離れる。**
> 2. **ノズルが 100 ℃以上のときは、電源を切らない。** 冷やすファンが止まり、熱が上に伝わって中の材料が溶け、ヘッドが詰まる・壊れる原因になる。電源は、ノズルが 100 ℃以下に下がってから切る。
> 3. **トラブルで電源を落としてしまったら、すぐに電源を入れ直す**（ファンを回して冷やすため）。
>    - ただし **煙・炎・焦げたにおいが出たときは別**。電源を切り、入れ直さず、すぐに担当者を呼ぶ（10-1）。
> 4. **部屋の換気をする。** 燃えやすい物をプリンタの近くに置かない。

## 0. いつもの造形（最短手順）

インストールと設定（2 章・3 章）が終わっていれば、毎回この手順で造形できる。分からない所は、右の章を読む。

| # | やること | 詳しく |
| --- | --- | --- |
| 1 | PrusaSlicer を起動し、右上の **Printer** が **slab S3DP555 用**になっているか見る | 3-B |
| 2 | モデル（STL など）を画面へドラッグ＆ドロップする | 5 章 |
| 3 | `F` キーで平らな面を下にする | 5 章 |
| 4 | 張り出しがあれば **Supports** を選ぶ。接地面が小さければ **Brim** にチェック | 5 章・6 章 |
| 5 | **Slice now** を押し、プレビューで形・サポート・1層目を確認する | 5 章 |
| 6 | **Export G-code** で `.gcode` を保存する（ファイル名は半角英数字） | 7 章 |
| 7 | プリンタの電源を入れ、テーブルの上を片付ける。冬は部屋を 20 ℃以上にする | 8-1 |
| 8 | Printrun（`pronterface.exe`）を起動し、ポートを選んで **Connect** | 8-2 |
| 9 | **Load file** で `.gcode` を読み込む | 8-3 |
| 10 | **Print** を押す | 8-5 |
| 11 | **1層目を最後まで見る**。問題があれば止める | 8-5 |
| 12 | 印刷中は PC をスリープさせない。USB ケーブルを抜かない | 8-6 |
| 13 | 終わったら、ノズルが 100 ℃以下に下がってから電源を切り、ヘラで造形物を外す | 8-7 |

> [!tip] 初めての人へ
> 最初の1回は、5 cm 角くらいの小さく平らなモデル（サポート不要の形）で練習する。大きいモデルは何時間〜何十時間もかかり、失敗したときの損も大きい。

## 1. 全体の流れ

![[prusaslicer_flow.excalidraw|1000]]

### 先に覚える言葉

| 言葉 | 意味 |
| --- | --- |
| フィラメント | 材料。細いひも状のプラスチックで、リール（スプール）に巻いてある。この運用では **PLA** を使う |
| ノズル | フィラメントを溶かして押し出す、ヘッドの先の細い口。とても熱くなる |
| テーブル（ベッド） | 造形物を乗せる台。温める機能がある |
| スライサー | 3D モデルを薄い層に切り分け、プリンタへの動作命令に変える。**PrusaSlicer** がこれ |
| スライス | スライサーで、モデルを動作命令に変える作業 |
| G-code | プリンタが読む動作命令のファイル（`.gcode`）。スライサーが作る |
| プリセット | 設定のまとまり。「プリンタ（Printer）」「フィラメント（Filament）」「印刷（Print）」の3種類がある |

## 2. インストール（Windows）

### 2-1. PrusaSlicer

1. Prusa 公式の PrusaSlicer のページ、または GitHub の Releases ページから、最新の**安定版**の Windows 用インストーラ（EXE）をダウンロードする。
   - GitHub ではファイル名に `win64` が付いたものを選ぶ。
   - `alpha` / `beta` / `rc`（試験版）と書かれたものは選ばない。
2. ダウンロードした EXE をダブルクリックし、画面の案内どおりに進める。
3. スタートメニューから **PrusaSlicer** を起動する。初回は「Configuration Wizard（設定ウィザード）」が開く（→ 3 章）。

> [!tip]
> - 「Drivers & Apps」という Prusa 純正機向けのまとめパッケージもあるが、PrusaSlicer だけ入れれば足りる。
> - 会社の PC で管理者権限が必要なときは、情報システム担当に相談する。

### 2-2. Printrun（Pronterface）

印刷専用 PC には導入済み。【要確認】社内 PC での置き場所（デスクトップのショートカットなど）。

自分で入れる場合:

1. GitHub の [Printrun の Releases](https://github.com/kliment/Printrun/releases/latest) から、`printrun-2.2.0_windows_x64_py3.10.zip` のように **`windows_x64`** が付いた zip をダウンロードする。
2. zip を展開し、中の `pronterface.exe` を起動する。
3. 「Windows によって PC が保護されました」と出たときは、ダウンロード元が上の GitHub であることを確かめてから、**「詳細情報」→「実行」**を押す（Printrun 公式 FAQ の手順。新しい版ごとに1回だけ）。

## 3. 初期設定と設定ファイル（.ini）の読み込み

設定の入れ方は2通りある。社内の設定ファイル（.ini）は作成済みなので、**3-B（共有フォルダから取得して読み込む）**を使う。3-A は、ファイルが使えないときの予備。

![[prusaslicer_setup_choice.excalidraw|1000]]

### S3DP555 の主な値

設定を確認するとき・作るときに使う。

| 項目 | 値 | 備考 |
| --- | --- | --- |
| 造形できる大きさ | 幅 500 × 奥行 500 × 高さ 500 mm | |
| ノズル径 | **0.5 mm**（標準） | 0.2 / 0.3 / 0.4 mm に交換できる。交換したら設定も変える |
| 層の厚さ | 0.05 ～ 0.4 mm | 京都大学の標準は 0.18 mm |
| PLA の温度 | ノズル **210 ℃**、テーブル **60 ℃** | 材料の袋の推奨温度も確認する |
| テーブルの最高温度 | 120 ℃ | |
| 1層目の高さ合わせ | 印刷を始めると、テーブル上の 16 点を測って**自動で補正**する | 開始 G-code に入っている必要がある（7-3） |
| フィラメント径 | 【要確認】1.75 mm か 2.85 mm か | |
| G-code の種類（flavor） | 【要確認】 | |

### 3-A. 設定ウィザードで設定する（ファイルが無い場合）

ウィザードは初回起動時に自動で開く。あとから開くには **Configuration → Configuration Wizard**。

1. **Welcome**: そのまま **Next**。
2. **Log in**（任意）: Prusa アカウントは不要。飛ばしてよい。
3. **Configuration Sources**: そのまま進む。
4. **Prusa Research / Other FFF**: S3DP555 は一覧に無いので、何も選ばずに進む。

   ![[03_wizard_other_fff.jpg|600]]

5. **Custom Printer**: 「Define a custom printer profile」にチェックを入れ、名前（例: `slab S3DP555`）を付ける。続く画面で、上の「S3DP555 の主な値」の表の値を入れる。

   ![[04_wizard_custom_printer.jpg|600]]

   | 画面 | 入れる内容 |
   | --- | --- |
   | Firmware | G-code の種類（G-code flavor） |
   | Bed Shape | テーブルの大きさ（500 × 500 mm） |
   | Build Volume | 造形できる最大の高さ（500 mm） |
   | Print Diameters | ノズル径（0.5 mm）、フィラメント径 |
   | Temperatures | ノズル温度（210 ℃）、テーブル温度（60 ℃） |

6. **Filaments**: 使うフィラメントを選ぶ。一覧に無ければ、あとで自分で作る。

   ![[05_wizard_filaments.jpg|600]]

7. **Other options**: 迷ったら初期値のまま。
8. **View mode**（表示モード）: **Simple / Advanced / Expert** から選ぶ。**Advanced** にしておく。サポートの細かい設定は Expert でないと出ないものがあるので、そのときだけ Expert にする。あとから画面右上、または **Configuration → Mode** で切り替えられる。

   ![[06_wizard_view_mode.jpg|600]]

9. **Finish** で完了。

> [!warning] 3-A で作った場合
> ウィザードで作った設定には、S3DP555 の開始 G-code（1層目の自動高さ補正など）が入っていない。そのまま印刷しない。開始 G-code の入れ方は、設定ファイルの管理者に確認する。

### 3-B. 共有フォルダから設定ファイル（.ini）を取得して読み込む

#### B-1. 共有フォルダから .ini を自分の PC にコピーする

1. エクスプローラーを開き、上のアドレス欄に共有フォルダのパスを貼り付けて `Enter` を押す。

   ```
   \\【サーバー名】\【共有名】\【フォルダ】
   ```

   【ユーザー記入】実際のパスに書き換える。社内の資料やメールのパスをコピーして貼ると間違えにくい。
2. 設定ファイル（【ユーザー記入】ファイル名: `○○○.ini`）を見つける。
3. **自分の PC（デスクトップなど）にコピーする**。共有フォルダ上のファイルを直接開かない（ネットワークが切れると読み込みに失敗するため）。
4. 共有フォルダが開けないとき:
   - 社内ネットワーク（または VPN）につながっているか。
   - パスの `\` の数、全角・半角が合っているか。
   - 権限が無いと言われたら、設定ファイルの管理者に連絡する。

> [!note] 設定ファイルが更新されたとき
> 同じ手順で取得し直し、もう一度読み込む。古いコピーを使い続けない。更新日は、共有フォルダのファイルの「更新日時」で確認する。【要確認】更新のお知らせ方法。

#### B-2. PrusaSlicer に読み込む

> [!warning] 読み込む前に
> .ini には2種類あり、**種類によって使うメニューが違う**。
> - **Config**（設定1セット）→ `Import Config`
> - **Config Bundle**（複数の設定のまとめ）→ `Import Config Bundle`
>
> どちらか分からなければ、ファイルを用意した人に聞く。間違えるとエラーになる（そのときはもう一方で読み込めばよい）。

1. メニュー **File → Import** を開く。

   ![[01_import_menu.jpeg|600]]

2. 次のどちらかを選ぶ。

   | 項目 | ショートカット | 使う場面 |
   | --- | --- | --- |
   | **Import Config…** | `Ctrl+L` | 設定1セット分の `.ini` を読み込む |
   | **Import Config Bundle…** | なし | 複数の設定が入った `.ini` を読み込む |

3. B-1 でコピーした .ini を選んで **開く**。
4. 画面右上のプリセット（Print settings / Filament / Printer）の一覧に、読み込んだ設定が出る。**Printer** で S3DP555 用のものを選ぶ。

   ![[07_printer_select.png|450]]

5. **Printer Settings**（画面上のタブ）を開き、次が S3DP555 の値（上の表）と合っているか見る。合っていないと印刷に失敗する。
   - テーブルの大きさ（Bed shape）
   - ノズル径（Nozzle diameter）、フィラメント径
   - 開始 G-code（Custom G-code → Start G-code）に、1層目の自動高さ補正が入っているか（【要確認】どの命令か。例: `G29`）

> [!tip] 読み込んだのに反映されないとき
> - 右上のプリセットが、読み込んだものに切り替わっているか見る。
> - 設定名の横に **(modified)** と出ていたら、保存していない変更がある。保存アイコン（フロッピーの絵）で名前を付けて保存する。
> - **2.9 系と 3.0 系の設定ファイルは互換性が無い**。違う版で書き出したファイルを読み込むと、プリンタ設定が壊れることがある。

### 3-C. 設定を保存・書き出す（バックアップ）

メニュー **File → Export** から行う。

![[02_export_menu.jpeg|600]]

| 項目 | 内容 |
| --- | --- |
| **Export Config…** | 今選んでいる設定1セットを `.ini` に保存 |
| **Export Config Bundle…** | 自分で作った設定をすべて `.ini` に保存（バックアップ向き） |
| **Export Config Bundle with Physical Printers…** | 上に加えて、ネットワーク接続するプリンタの API キーと IP アドレスも保存。**他の人に渡すファイルには使わない** |

> [!tip] 設定フォルダの場所（Windows）
> 通常は `%APPDATA%\PrusaSlicer`（`C:\Users\<ユーザー名>\AppData\Roaming\PrusaSlicer`）。エクスプローラーのアドレス欄にそのまま貼り付けて開ける。

## 5. モデルを読み込んでスライスする

### 手順

1. **モデルを読み込む**: ファイルを画面にドラッグ＆ドロップするか、`Ctrl+I`。読み込める形式は STL、3MF、STEP、OBJ、AMF。
   - 3MF を開くと、ファイルに入っている設定で**今の設定が置き換わる**ことがある。確認の画面が出たら、内容を読んでから選ぶ。
2. **向きを決める**: `F` を押して、下にしたい平らな面をクリックする。回すときは `R`。
   - 平らで広い面を下にすると、倒れにくく、サポートも減る。
3. **プリンタを選ぶ**: 右上の **Printer** で S3DP555 用のものを選ぶ。

   ![[07_printer_select.png|450]]

4. **フィラメントを選ぶ**: **Filament** で、今プリンタに付いている材料（PLA）を選ぶ。

   ![[08_filament_selection.png|300]]

5. **印刷設定を選ぶ**: **Print settings** で層の厚さ（Layer height）を選ぶ。最初は **0.2 mm 前後**（社内の設定ファイルに入っているもの）にする。薄いほどきれいだが、時間がかかる。

   ![[09_print_settings.png|500]]

6. **インフィル（中身の詰まり具合）**: 最初は **15%** 前後で十分。強さが必要な部品は上げる（時間と材料が増える）。

   ![[11_infill.png|500]]

7. **ブリム（Brim）**: テーブルに接する面が小さいモデルはチェックを入れる。周りに薄い縁が付き、剥がれにくくなる。

   ![[12_brim.png|500]]

8. **サポート**: 張り出した部分があれば、6 章を見て設定する。
9. **スライス**: 右下の **Slice now**（`Ctrl+R`）を押す。自動でプレビューに切り替わる。
10. **プレビューで確認する**（必ず行う）:
    - 右側の縦のスライダーを上下に動かして、1層ずつ形を見る。
    - 空中に浮いている部分が無いか（あればサポートが必要）。
    - 1層目が、テーブルにしっかり広がっているか。
    - モデルがテーブルの外にはみ出していないか。
    - 右下の **Sliced Info**（または左上の表示）で、**印刷時間**と**材料の量**を確認する。長すぎるときは、大きさ・インフィル・層の厚さを見直す。

    問題があれば `Tab` で 3D ビューに戻り、向きやサポートを直してスライスし直す。

## 6. サポート材の取り付けと種類の選び方

**サポート材**は、空中に張り出した部分（オーバーハング）を下から支える、あとで取り外す柱のようなもの。空中には材料を置けないため、支えが要る。

![[10_supports_needed.jpg|600]]

*サポートが必要なモデル（左）と、サポートが生成されたモデル（右）*

### 6-1. まず「サポートが要るか」を決める

![[prusaslicer_support_choice.excalidraw|1000]]

> [!note] 目安
> 「張り出しの角度が、水平から約 45° より寝ている部分」は支えが要る。まず向きを変えて、張り出しを減らせないか考える。

### 6-2. 右パネルの「Supports」の選び方

画面右上の **Supports** で選ぶ。

| 選択肢 | 動き | 使う場面 |
| --- | --- | --- |
| **None** | サポートなし（初期値） | 張り出しの無いモデル |
| **Support on build plate only** | テーブルの上からだけ柱を立てる | 張り出しの真下がテーブルのモデル。跡が少ない |
| **For support enforcers only** | 自分で塗った所だけに付ける（6-4） | 手で細かく指定したいとき |
| **Everywhere** | モデルの上からも柱を立てる | 張り出しの真下がモデル自身のとき |

![[16_support_everywhere_vs_plate.jpg|600]]

*テーブルからのみ（左）と、すべての場所（右）。「すべて」ではモデルの上にもサポートが立つ*

> [!warning] よくある失敗
> ここが **None** のままだと、ほかの設定をしてもサポートは出ない。

### 6-3. サポートの形（Style）を選ぶ

| --- | --- | --- |
| **Grid** | 格子状。安定している。モデルの壁にも触れやすい | 迷ったらこれ |
| **Snug** | 張り出しの形にぴったり沿う。壁に触れにくい。高く細い柱は倒れやすい | 小さい部品、平らな張り出し |
| **Organic** | 木の枝のような形。外しやすく、跡が残りにくく、材料も少ない | 複雑な形、フィギュアなど |

*Grid（左）と Organic（右）*

#### Organic の主な設定

### 6-4. サポートを手で塗る（Paint-on supports）

自動のサポートでは足りない・多すぎるときに、手で追加・禁止できる。表示モードが **Advanced か Expert** のときだけ使える。

1. モデルをクリックして選ぶ。
2. 左のツールバーの **Paint-on supports** のアイコンをクリックする。

   | `Alt` ＋ ホイール | ブラシの大きさを変える |

4. 右パネルの **Supports** を、塗り方に合わせて変える。
   - 追加だけ塗った → **For support enforcers only**

### 6-5. サポートの強さと外しやすさの調整（Expert モード）

**Print Settings → Support material** の主な項目。

| 項目 | 意味・調整の目安 |
| --- | --- |
| **Overhang threshold** | 「サポートなしで印刷できる、いちばん寝た角度」（水平から測る。90 が垂直）。**大きくするほどサポートが増え、小さくするほど減る**。0 は自動 |
| **Enforce support for the first N layers** | 下から N 層は、条件に関係なくサポートを付ける。細い物が倒れるときに使う |
| **Contact Z distance（Top / Bottom）** | サポートとモデルの上下のすき間。広いと外しやすいが、張り出しの下の面が荒れる |
| **XY separation** | サポートとモデルの横のすき間。広いと外しやすいが、支えが弱くなる |
| **Pattern** | サポートの模様。Rectilinear（初期値）がいちばん外しやすい。Honeycomb は丈夫だが外しにくい |
| **Pattern spacing** | 模様の間隔。広げると外しやすいが、サポートの上の面が垂れやすい |
| **Top / Bottom interface layers** | 接する面を密にする層の数。増やすと面はきれいだが外しにくい |
| **Don't support bridges** | ブリッジ（両端が支えられた横渡し）の下にサポートを付けない |

### 6-6. サポートの取り外しのコツ

- テーブルとモデルが冷めてから外す。
- ニッパーやラジオペンチで、サポートの根元から少しずつ折る。**刃物は自分の体の方へ向けない。**
- 跡はカッターやヤスリで整える。
- 外しにくいときは、Contact Z distance を広げる、Snug や Organic を試す、Interface layers を減らす。

## 7. G-code の生成と出力

### 7-1. スライスと確認

1. **Slice now** を押す。
2. プレビューで形・サポート・1層目・印刷時間を確認する（5 章の手順 10）。

### 7-2. 出力

プレビューで問題がなければ、右下の **Export G-code**（`Ctrl+G`）を押し、保存先を選ぶ。

![[14_export_gcode.jpeg|600]]

- **Printrun で使うのは `.gcode`**。ファイル名が `.bgcode`（圧縮した形式）になったときは、**Printer Settings → General** の **Supports binary G-code** のチェックを外す（Expert モードで表示される）。
- 保存先は、自分の PC の分かりやすいフォルダにする。ファイル名は**半角英数字**にする（例: `bracket_v2.gcode`）。
- この運用では SD カードや USB メモリは使わない。Printrun が USB ケーブルでプリンタに送る（8 章）。

### 7-3. 印刷前の確認（スライサー側）

- [ ] 右上の **Printer** が S3DP555 用になっている。
- [ ] **Filament** が、今プリンタに付いている材料（PLA）になっている。材料を変えたら、**スライスし直して出力し直す**（9-3）。
- [ ] モデルがテーブルからはみ出していない。
- [ ] 開始 G-code に、原点復帰・加熱・**1層目の自動高さ補正**が入っている（社内の設定ファイルを使っていれば入っている。【要確認】）。
- [ ] ファイルが `.gcode` になっている。

## 8. Printrun で造形する

**Printrun（Pronterface）** は、PC から USB ケーブルでプリンタに G-code を送って印刷させる、無料のソフト。

![[prusaslicer_print_flow.excalidraw|1000]]

> [!danger] 印刷を始めたら
> **1層目は必ず最後まで見てから席を離れる。**

### 8-1. プリンタの準備

1. プリンタの**電源を入れる**（京都大学の機体では、本体の左側の奥にスイッチがある。【要確認】社内機の位置）。
2. **テーブルの上を片付ける**。前の造形物、ゴミ、工具が残っていないか。
3. **テーブルの糊**を確認する。うっすら白くなっていれば十分。剥げている所だけ、スティック糊を**薄く**塗る（塗りすぎると、かえって剥がれやすくなる）。
4. **材料**が十分に残っているか、リールから絡まずに出てくるかを見る。色や材料を変えるときは 9 章。
5. 冬は**部屋の暖房を入れ、20 ℃以上**にする。印刷が終わるまで暖房は切らない（冷えると反りや剥がれの原因になる）。
6. **USB ケーブルで PC とプリンタをつなぐ**。

### 8-2. Printrun をプリンタにつなぐ

1. `pronterface.exe` を起動する。
2. 画面左上で**ポート名**（`COM3` など）を選ぶ。【ユーザー記入】S3DP555 のポート名: `COM__`（分からないときは、Windows の「デバイスマネージャー」→「ポート (COM と LPT)」で、USB ケーブルを抜き差しして増減するものを探す）。
3. **ボーレート**（通信の速さ）を選ぶ。【ユーザー記入】S3DP555 のボーレート: `______`（多くの機種は 115200 か 250000）。
4. **Connect** を押す。
5. つながると、右の表示欄にプリンタからの応答が流れ、ノズル（Heater）とテーブル（Bed）の温度が表示される。

![[printrun_pronterface.png|800]]

*Pronterface の画面（Printrun 公式の画面例）。古い Linux 版の画面なので、Windows 版とは見た目が少し違う。*

| 位置（画面例） | 名前 | 役割 |
| --- | --- | --- |
| 左上 | **Port** / ボーレート / **Connect** | ポートとボーレートを選んで接続する |
| その右 | **Load file** | G-code を読み込む |
| その右 | **Print** / **Pause** | 印刷を始める / 一時停止する（接続して G-code を読み込むまで押せない） |
| 左の円盤・縦バー | 移動ボタン | ヘッドとテーブルを動かす。数字（0.1 / 1 / 10 / 100）は動く距離（mm）。**Motors off** はモーターの力を抜く |
| 左下 | **Heat** / **Bed** | ノズル / テーブルの目標温度。数字を入れて **Set**、止めるときは **Off** |
| その下 | **Extrude** / **Reverse** | 材料を押し出す / 引き戻す。材料の交換で使う |
| 中央 | 3D ビュー | 読み込んだ G-code の形 |
| 右 | 表示欄 | プリンタからの応答。下の欄から G-code を直接送れる（普段は使わない） |

> [!warning]
> 移動ボタンと **Extrude** / **Reverse** は、プリンタを**本当に動かす**。印刷中は押さない。

> [!tip] つながらないとき
> - 別のソフト（他の Printrun、スライサーなど）が同じポートを使っていないか。閉じてからやり直す。
> - ポート名・ボーレートが合っているか。
> - USB ケーブルを差し直す。充電専用のケーブルではつながらない。
> - プリンタの電源が入っているか。

### 8-3. G-code を読み込む

1. **Load file** を押し、7 章で保存した `.gcode` を選ぶ。
2. 中央の 3D ビューにモデルが出る。形が正しいか、テーブルに収まっているかを見る。
3. 層ごとに確認したいときは、別ウィンドウの層の表示を使う（下の画像）。

   ![[printrun_pronterface2.png|450]]

   *G-code の層の表示（Printrun 公式の画面例）。下のバーに「Layer 11 - Z = 2.340 mm」のように、見ている層が出る。*

4. 3D ビューの操作:

   | 操作 | 動き |
   | --- | --- |
   | ホイール | 拡大・縮小 |
   | 左ドラッグ | 回転 |
   | 右ドラッグ | 移動 |
   | `Shift` ＋ ホイール、`↑` / `↓` | 層を送る |
   | `R` / `F` | 視点のリセット / 全体を表示 |

> [!note]
> Printrun にも STL を読み込む機能があるが、この運用では使わない。**必ず PrusaSlicer で作った `.gcode` を読み込む。**

### 8-4. 加熱する（必要なときだけ）

G-code の最初に加熱の命令が入っているので、**Print を押せば自動で温まる**（【要確認】社内の開始 G-code）。

先に温めておきたいときは、左下の **Heat**（ノズル）に `210`、**Bed**（テーブル）に `60` を入れて、それぞれ **Set** を押す。止めるときは **Off**。温度は右の表示や温度のグラフで確認する。

### 8-5. 印刷を開始し、1層目を確認する

1. **Print** を押す。
2. プリンタは次の順に動く。動いている間は、手を中に入れない。
   1. 原点に戻り、ノズルとテーブルを温める。
   2. テーブルが上がり、**16 点で高さを測る**（自動高さ補正）。
   3. テーブルの左手前で、ノズルの先の余分な材料を拭う。
   4. モデルの周りに1周、線を引く（**スカート**。ノズルの出を安定させるため）。
   5. モデルの1層目を作る。
3. **1層目を最後まで見る**。次のようになっていれば OK:
   - 線がテーブルに押し付けられて、平たくなっている。
   - 線が途切れず、隣の線とくっついている。
   - 1層目は他の層より材料が多いので、**少し粗く見えるのは問題ない**。
4. 次のようなら **NG**。印刷を止めて原因を調べる（11 章）:
   - 線が丸いまま転がっていたり、テーブルから剥がれたりする。
   - 材料が玉になってノズルに付いてくる、糸のように空中に浮く。
   - ノズルがテーブルや造形物を引きずっている、こすれる音がする。
   - 材料がまったく出ていない。
5. **止め方**: Printrun の **Pause** を押して送信を止める。【要確認】そのあとの操作（ヘッドを逃がす、加熱を **Off** にする、本体のツマミで中止できるか）。止めたら、テーブルの上の途中の造形物を取り除き、原因を直してからやり直す。
6. 問題がなければ、表示された残り時間を確認して、席に戻ってよい。

> [!danger]
> **1層目は必ず最後まで見てから席を離れる。** 失敗したまま放っておくと、ノズルに材料が詰まったり、剥がれた造形物が機械に引っかかったりして、故障の原因になる。

### 8-6. 印刷中の注意

- 印刷には**印刷専用 PC** を使う。印刷中は、この PC で別の作業をしない。
- **PC をスリープ・シャットダウン・再起動させない。** Printrun は PC から命令を送り続けているので、PC が止まると印刷も止まる。【要確認】印刷専用 PC で、スリープを無効にし、Windows Update の自動再起動を止めてあるか。
- **USB ケーブルを抜かない・踏まない。** 印刷が止まる。
- 一時停止は **Pause**。もう一度押すと再開する（ボタンの文字が **Resume** に変わる）。
- 長い印刷は、ときどき様子を見に来る（11 章の症状が出ていないか）。
- 材料が途中で切れたときの動きは【要確認】（SD カードで印刷したときは、自動で止まって「フィラメントコウカン」と表示される。USB で印刷したときに同じように止まるかを確かめる）。

> [!note] 長い印刷について
> S3DP555 は大きな物が作れるため、印刷が何十時間にもなることがある。その間ずっと PC から送り続ける必要がある。【要確認】長時間の印刷だけ SD カードを使うかどうかの社内ルール。

### 8-7. 印刷が終わったら

1. 右の表示欄で、印刷が終わったことを確認する。
2. ノズルとテーブルが**冷めるのを待つ**。ノズルの温度が **100 ℃以下**になったことを確認する。
3. Printrun の **Disconnect**（切断）を押す。
4. **プリンタの電源を切る**（ノズルが 100 ℃以下になっていることを、もう一度確認してから）。
5. **ヘラ**をテーブルと造形物の間に差し込み、力を入れる。パキッと音がして剥がれたら、手で持って外す。
   - ヘラは自分の手の方へ向けない。
6. テーブルに残ったスカートなどのゴミを取り、プラスチックのゴミ箱に捨てる。テーブルの糊はそのままでよい。
7. サポートがあれば取り外す（6-6）。

## 9. 材料（フィラメント）の交換

色や材料を替えるときの手順。京都大学の S3DP555 の手順をもとにしている。【要確認】社内機のヘッドの作りが同じか（バネ・リング・半透明の部品の位置）。

### 9-1. 準備

- 新しい材料（PLA）、ハサミかニッパー、ウエス（布）、ピンセット。
- 材料の**推奨温度**を確認する（リールのラベルや袋に書いてある）。PLA は、ノズル 210 ℃前後、テーブル 60 ℃前後。
- 印刷していないときに行う。

> [!warning]
> - **冷えたまま材料を引き抜かない。** 必ずノズルを温めてから行う。
> - ノズルとその周りは 200 ℃以上になる。素手で触らない。

### 9-2. 取り外しと取り付け

1. Printrun でプリンタに接続し、**Heat** に `210` を入れて **Set** を押す。温度が 210 ℃に達するまで待つ。
2. **Motors off** を押す。ヘッドが手で前後左右に動かせるようになるので、作業しやすい位置へ動かす。
3. **古い材料を外す**:
   1. ヘッドの上のバネの、奥側の端をネジから外す。
   2. 材料が入っている所の**黒いリング**を下に押しながら、材料を通しているチューブを上に引き抜く。
   3. **半透明の部品**を奥に倒し、材料を上にゆっくり引き抜く。抜けにくいときは、少し押し込んでから引き抜く。
   4. 外した材料はリールに巻き取り、端をリールの穴に留めて（ほどけないように）袋に入れて保管する。
4. **新しい材料を付ける**:
   1. 新しいリールを取り付ける。
   2. 材料の先を、ハサミで**斜めに**切る（入れやすくするため）。
   3. 材料を、本体の左奥にある**材料センサー**に通してから、チューブに差し込む（センサーは材料切れを見つけるためのもの。通さないと材料切れが分からない）。
   4. 半透明の部品を前後に調整しながら、材料をノズルの奥まで入れる。
   5. チューブを付け直し、バネの端をネジに掛け直す。
5. **押し出して色を入れ替える**: Printrun の **Extrude** を押し、ノズルから材料が出ることを確認する。前の色が混ざらなくなり、**新しい色だけ**が出るまで繰り返す。【要確認】1回に押し出す長さ（mm）と速さ。
   - 前の色がなかなか抜けないときは、専用の清掃棒でノズルの中を掃除する（【要確認】社内の手順）。
6. 出てきた材料を、ピンセットで取り除く（熱いので注意）。
7. すぐに印刷しないときは、**Heat** の **Off** を押して冷ます。電源はノズルが 100 ℃以下になってから切る。

### 9-3. スライサー（PrusaSlicer）側の設定

材料を替えたら、スライサー側も合わせる。

1. 右上の **Filament** で、使う材料のプリセットを選ぶ。
2. **Filament Settings → Filament** で、ノズル温度・テーブル温度を確認する（この温度が G-code に書き込まれる）。
3. 変えたときは、保存アイコンで**名前を付けて保存**する。
4. **スライスし直し、G-code を出力し直す。** 前に作った G-code には、前の材料の温度が入っている。
5. 新しい G-code を Printrun で読み込み直す。

> [!tip]
> - 色が違うだけなら、温度は同じでよいことが多い。メーカーが変わるときは推奨温度を確認する。
> - PLA は湿気を吸うと、糸を引いたり表面が荒れたりする。使わないときは乾燥剤と一緒に袋に入れて保管する。

## 10. 3Dプリンタを使うときの注意事項

> [!danger] 必ず守ること
> 1. **1層目は必ず最後まで見てから席を離れる。** 失敗していたら、その場で止めて原因を調べる。
> 2. **ノズルが 100 ℃以上のときは、電源を切らない。**
>    - 電源を切ると、ヘッドを冷やすファンも止まる。ノズルの熱が上に伝わり、まだ溶けてはいけない所で材料が溶けて固まり、詰まりや故障の原因になる。
>    - 電源は、ノズルが 100 ℃以下に下がってから切る。
> 3. **トラブルで電源を落としてしまったら、すぐに電源を入れ直す。** ファンを回して冷やすため。そのまま放置しない。
>    - 【要確認】入れ直したあとの手順（ファンが回っているかの確認、途中の造形物の扱い）。
> 4. **ただし、煙・炎・焦げたにおいが出たら、電源を切り、入れ直さない。** すぐに離れて担当者を呼ぶ（10-1）。

### 10-1. 火災・異常のとき

- 煙・炎・焦げたにおい・大きな異音が出たら、**電源を切り**、プリンタから離れて、すぐに担当者を呼ぶ。【ユーザー記入】担当者・連絡先: `______`
- 炎が出ているときは、無理に近づかず、周りの人に知らせる。消火器の場所を事前に確認しておく。【ユーザー記入】消火器の場所: `______`
- プリンタの周りに、紙・段ボール・スプレー缶などの燃えやすい物を置かない。

### 10-2. 換気

- 材料を溶かすと、PLA でも、においや目に見えないとても細かい粒子が出る。**部屋の換気をする。**
- プリンタのすぐ横で長時間作業しない。気分が悪くなったら、部屋を出て担当者に伝える。

### 10-3. やけど

- 印刷中と印刷直後は、**ノズル（約 210 ℃）とテーブル（約 60 ℃）が熱い**。素手で触らない。
- 造形物の取り外しは、**冷めてから**行う。温まった状態で作業するときは、ピンセットなどの道具を使う。
- ノズルから出てきた材料も熱い。

### 10-4. 動く部分・挟まれ

- 動いているときは、**ヘッドやテーブルが動く範囲に手を入れない**。
- 長い髪はまとめる。袖、ネックストラップ、手袋が巻き込まれないようにする。
- 中で作業するときは、動きが止まっていることを確かめてから行う。

### 10-5. 使う前のチェック

- [ ] テーブルの上に、前の造形物やゴミ、工具が残っていない。
- [ ] テーブルに糊がうっすら塗られている。
- [ ] 材料が十分に残っていて、絡まずに出てくる。
- [ ] ヘッドの周りに、ケーブルや物が当たらない。
- [ ] 部屋が換気されている。冬は 20 ℃以上ある。
- [ ] プリンタの周りに燃えやすい物が無い。

## 11. トラブルシューティング

まず**症状から探す**。

![[prusaslicer_troubleshoot_map.excalidraw|1000]]

### 11-1. 1層目がつかない・途中で剥がれる

| 確認すること | 対処 |
| --- | --- |
| テーブルの糊が剥げている・汚れている | ゴミを取り、糊を**薄く**塗り直す。塗りすぎも剥がれの原因 |
| 1層目の高さが合っていない（線が丸い・浮く、または潰れすぎ） | 開始 G-code に自動高さ補正が入っているか確認する（7-3）。それでも直らなければ担当者に相談する（【要確認】高さの調整方法） |
| 接地面が小さい | **ブリム**を付ける（5 章） |
| 温度が合っていない | ノズル 210 ℃・テーブル 60 ℃（PLA）になっているか。材料の推奨温度も確認 |
| 部屋が寒い | 冬は 20 ℃以上にする |

### 11-2. 角が反って浮く（Warping）

材料が冷えて縮むときに、角が引っ張られて浮き上がる。

- **ブリム**を付ける。
- テーブルの糊を確認する。
- 部屋を暖める（冬は 20 ℃以上）。窓際やエアコンの風が当たる場所を避ける。
- 印刷の速さを少し下げる。
- 材料に合ったファンの強さにする（PLA は強め）。材料用の標準プリセットを使う。

### 11-3. 糸を引く・ノズルから垂れる（Stringing / Oozing）

![[27_stringing_a.jpg|450]]

*糸引きの例。造形物の間に細い糸が張っている*

リトラクション（移動するときに材料を少し引き戻す動き）の設定画面（Printer Settings → Extruder 1）。

![[28_stringing_settings.jpeg|600]]

| 対処 | 設定の場所 |
| --- | --- |
| ノズル温度を **5 ～ 10 ℃ 下げる** | Filament Settings → Filament → Temperature |
| リトラクションを調整する | Printer Settings → Extruder 1 → Retraction |
| **Avoid crossing perimeters** を有効にする | Print Settings → Layers and perimeters → Quality |
| **Only retract when crossing perimeters** を有効にする | Print Settings → Infill → Advanced |
| 材料が湿気を吸っていないか確認し、別のリールで試す | － |
| ノズルを掃除する | － |

> [!tip]
> 細い糸は、ヒートガンを 1 ～ 2 秒当てると取れることがある。当てすぎるとモデルが変形する。ヒートガンを使うときは担当者に相談する。

### 11-4. 途中で位置がずれる（Layer shift）

![[30_layer_shift_stair.jpg|500]]

*X 方向にずれた例（右上の拡大図の、胴の途中でずれている）*

主に**機械側**の問題で、スライサーの設定では直らないことが多い。**自分で機械を分解しない。担当者に相談する。**

担当者が確認すること:

- ベルトの張りが緩い、またはばらついている。
- モーターのプーリー（歯車）の止めネジが緩んでいる。

  ![[31_pulley_setscrew.png|400]]

- 配線・結束バンド・ゴミが動く部分に引っかかっている。
- 印刷が速すぎる。大きい・複雑なモデルは速さを下げる。
- 反り上がった部分にノズルがぶつかっている（ファンを強める、モデルを分ける）。

> [!note]
> 公式の手順は Prusa 製プリンタ向け。S3DP555 の調整は、機体のマニュアルかメーカーに確認する。

### 11-5. サポートが出ない・多すぎる・外れない

| 症状 | 確認すること |
| --- | --- |
| サポートがまったく出ない | 右パネルの **Supports** が **None** のままではないか |
| 塗っても出ない | **For support enforcers only**（または Everywhere）になっているか |
| 禁止を塗ったのに出る | **Everywhere** か **Support on build plate only** になっているか。禁止は「そこからサポートを立てない」指定で、上から下りてくるサポートは止めない。細かく塗りすぎると反映されないこともある |
| サポートが多すぎる | **Overhang threshold** を**小さく**する。**Support on build plate only** にする |
| サポートが少なすぎる・崩れる | **Overhang threshold** を**大きく**する。**Enforce support for the first N layers** を使う |
| 外れない・跡が残る | Contact Z distance を広げる。Snug・Organic を試す。Interface layers を減らす |

### 11-6. 設定ファイルが読み込めない

| 症状 | 原因と対処 |
| --- | --- |
| エラーが出て読み込めない | `Import Config` と `Import Config Bundle` を取り違えている。もう一方で試す |
| 読み込んだのに設定が出ない | 右上のプリセットを切り替える。(modified) があれば保存する |
| 読み込んだらプリンタ設定が壊れた | 違う版の設定ファイル。2.9 系と 3.0 系は互換性が無い。同じ版で書き出したファイルを使う |
| 他のスライサー（OrcaSlicer など）の設定が読めない | PrusaSlicer では読めない。PrusaSlicer 用の設定を使う |
| 設定を全部やり直したい | **Configuration → Configuration Wizard** の最初の画面（Welcome）で、ユーザーの設定をすべて消す項目を選ぶ。**自分で作った設定も消える**ので、先に 3-C でバックアップを取る |

### 11-7. その他

| 症状 | 対処 |
| --- | --- |
| モデルがテーブルからはみ出す | Printer Settings の Bed shape と Max print height が 500 mm になっているか確認する。大きすぎるモデルは縮小（`S`）するか、カットして分ける |
| STL に穴・エラーがある | 右下の情報に「Auto-repaired errors」と出ていれば自動で直っている。形が崩れていないかプレビューで確認する |
| スライスで警告が出る | 内容を読み、サポートや向きを見直す |
| Printrun で印刷が始まらない・途中で止まる | ファイルが `.gcode` か、ポート名・ボーレート、USB ケーブル、PC のスリープ設定を確認する（8 章） |
| 材料が出ない | 材料が切れていないか、センサーに通っているか、ノズルが詰まっていないか（9 章）。直らなければ担当者に相談する |
| 電源を落としてしまった | **すぐに電源を入れ直す**（10 章）。煙・においがあるときは入れ直さず、担当者を呼ぶ |

## 12. 用語集

| 用語 | 意味 |
| --- | --- |
| FDM / FFF（熱溶解積層） | 熱で溶かしたプラスチックを、1層ずつ積み重ねて形を作る方式。S3DP555 はこれ |
| PLA | 植物由来のプラスチック。反りにくく扱いやすい。熱には弱い（約 60 ℃で柔らかくなる） |
| フィラメント | 材料。ひも状のプラスチック |
| ノズル | 材料を溶かして押し出す口 |
| ヘッド | ノズル・ファン・材料を送る仕組みが付いた、動く部品 |
| テーブル / ベッド | 造形物を乗せる台 |
| スライサー | 3D モデルを G-code に変えるソフト（PrusaSlicer） |
| G-code | プリンタへの動作命令のファイル |
| Printrun / Pronterface | PC からプリンタに G-code を送って印刷させるソフト |
| COM ポート | PC が USB でつないだ機器を呼ぶ名前（`COM3` など） |
| ボーレート | 通信の速さ。PC とプリンタで合わせる |
| プリセット | 設定のまとまり（Print / Filament / Printer） |
| レイヤーハイト（層の厚さ） | 1層の厚さ。薄いほどきれいだが時間がかかる |
| インフィル | モデルの中身の詰め方。% が大きいほど丈夫で重い |
| オーバーハング | 下に支えの無い張り出し |
| ブリッジ | 両端が支えられた空中の横渡し |
| サポート | 張り出しを下から支える、あとで取る柱 |
| ブリム | 1層目の周りに付ける薄い縁（剥がれ防止） |
| スカート | モデルの周りに少し離して引く線（ノズルの出を安定させる） |
| リトラクション | 移動するときに材料を少し引き戻して、糸引きを防ぐ動き |
| Enforcer / Blocker | サポートを付ける / 付けない、と塗った指定 |
| IPA（イソプロピルアルコール） | 汚れ・油を拭き取るアルコール |
