## Text Elements
画像の容量を縮小 処理フロー図 ^title
① 画像を右クリック ^step1-title
マークダウン内またはファイルメニューで「画像の容量を縮小」を選択 ^step1-desc

③ 目標容量（KB）の指定 ^step3-title

app.vault.modifyBinary で上書き保存し、画面内の画像表示を即座に更新 ^step5-desc
