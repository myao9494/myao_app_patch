# Excalidraw Data

## Text Elements
画像選択時のRキーリネーム & モーダルドラッグ移動フロー ^title
① マークダウン上で画像をクリックして選択 ^step1-title
画像にハイライト枠線が付与され、選択状態パスを保持 ^step1-desc
② ショートカットキー R または r を押下 ^step2-title
keyup検知または安全遅延起動でキーストローク余波を完全遮断 ^step2-desc
③ ImageRenameModal が起動 & 元の名前が全選択ハイライト保持 ^step3-title
タイトルバー（h2）でドラッグ移動可能！持続自動復元で元の名前（IMG_0710）を確実に表示 ^step3-desc
④ ファイル名をそのまま利用して編集し Enter / 保存 ^step4-title
既存の名前がデフォルトで維持されるため、末尾追加や一部編集にそのまま活用可能！ ^step4-desc
